## 静态审查要点

- 上层目标逐情景乘同一权重；合约和库存特征按同一权重中心化。当前合约不使用当前交付误差；未来原q使用午夜前一期特征，未来r使用合法调整节点前一期特征。前六小时r强制等于q。
- 价格特征在电池状态中滞后一段；在下一合同节点可以纳入刚披露价格。真实回放的ep/zp更新放在实际电池动作后，当前实际价格只用于随后账单。
- M1仅回归下一净需求误差与本段价格误差两行，EMA行由恒等式补出。回归用缩减前成熟历史块，不拼接不同块末首。净需求/EMA和价格/EMA分别共享尺度。
- 当前M1在情景外生支持上先算转移/价格，再对实际x作非负核插值；权重不依赖库存，保持对E的凸性。它是明确的近似支持模型，不是精确连续状态Bellman，也不是原过程因果下界。
- 现有M0在三状态且均匀概率时直接复用旧MarkovDP。非均匀权重转移使用S倍概率形成伪计数，再加原量级平滑；这一做法保持均匀退化一致，但属于模型平滑约定，S改变也会改变转移平滑，必须在解释中披露。
- 真终点由同一冻结执行器的可达库存区间强制；LP在真正到达评价末段时施加硬目标，DP仍是有限罚项加实际硬投影。不得把DP有限罚项表述成单独证明硬终端。
