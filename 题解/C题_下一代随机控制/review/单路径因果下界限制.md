# 单路径因果下界的限制

独立审查者：`/root/independent_review`。结论：**所述论证在本题已声明的物理、信息和收费口径下成立**，但须区分逐路径下确界、预先承诺的共同策略和期望最优值。本记录仅为理论核对，未运行升级模型，不构成升级 gate 通过。

令 Π 为所有满足合法发布时间和观测顺序的可测策略，初始库存及指定终端条件固定；不另限制策略复杂度或设计方法。令 \(J_{\rm PI}(\omega)\) 为同一物理/合同问题在固定路径 ω 上放松信息约束后的最优费用。显然，对每个 \(\pi\in\Pi\)，都有

\[
J_{\rm PI}(\omega)\le J(\pi,\omega).
\]

反向不等式需要可行延伸，不能只说“沿此路径可行”。固定一条 ω，取其完美信息最优合同发布表和电池充放电/库存序列，并将它们作为按时间预先给定的常数，构造一项策略 \(\pi_\omega\)。它在规定节点发出常数 q/r，电池执行固定可行序列；对任意另一净需求路径 n，按当前已观察净需求设置

\[
e_t=\max(n_t+c_t-d_t-r_t,0),\qquad
w_t=\max(r_t+d_t-c_t-n_t,0).
\]

本题紧急购电无已给出的容量上限，允许免费弃置总富余，因此该补救在其他路径仍可行。q/r 保持非负；电池功率、互斥、库存上下界及库存递推均不依赖实际净需求；固定库存序列自动保持相同初末约束，包括规定的全局 6000 终点。未来价格既不影响这一物理可行性，也不作为在线决策输入。常数来自哪条路径，只是索引了策略集合中的不同成员。

于是该策略在原 ω 上达到完美信息值；若最优值不取到，可改用任意精度的近最优序列，结论写作下确界。故

\[
\boxed{\inf_{\pi\in\Pi}J(\pi,\omega)=J_{\rm PI}(\omega).}
\]

**合同及 oracle 口径也能对齐。** 对当前采用的相对 0 点最终净额结算，

\[
\phi(q,r)=r+\tfrac12|r-q|.
\]

当实际价格非负时，任意路径可行方案均可在完美信息问题中改为 0 点普通购电 \(q'_t=r_t+e_t\)、不调约、无紧急购电，保留原电池及弃电。它的费用 \(p_t(r_t+e_t)\) 不高于 \(p_t\{\phi(q_t,r_t)+5e_t\}\)。反过来，普通购电 oracle 又是完整问题的允许特例。因此本项目“普通购电、无紧急、无调约”的完整路径 LP 与同口径完整完美信息最优值相等，并非仅凭名称就认定相等。第一问或每日闭合对照也须使用各自相同的初末约束。若价格允许负值、购电有上限、弃电受限或改用其他收费公式，需重新审查这一步；不能直接复用现有 oracle 数值。

关键限定是：\(\pi_\omega\) 随 ω 改变。一个实际控制器不能先看到测试路径再选择它；也没有证明存在同一因果策略对所有路径同时达到完美信息值。禁止价格预见的规则仍完全有效：每个被固定下来的常数策略本身可测，但按实际未来选择策略这一选择器通常不可测。

因此，若一个逐路径数值 B 要对**所有**上述因果策略保证 \(B(\omega)\le J(\pi,\omega)\)，它不可能严格高于 \(J_{\rm PI}(\omega)\)。这不否认期望信息成本：对事先声明的概率律 P，一般只有

\[
\mathbb E_P J_{\rm PI}(\omega)
=\mathbb E_P\inf_\pi J(\pi,\omega)
\le\inf_\pi\mathbb E_PJ(\pi,\omega),
\]

不能交换期望与下确界，也不能用一个期望下界直接约束单次路径账单。已知/明确假设的概率律可支持模型内期望因果界；事先限制的策略类也可有更高的类内逐路径界，但这两个对象均不同于无约束 Π 的通用路径界。高概率界还需相应统计假设，不能从一条路径凭空得到。

本证明依赖本题的充分补救能力。若另加电网容量、禁止紧急购电或弃电、路径依赖终端要求、其他会使固定电池序列无法跨路径延伸的约束，则上述构造可能失败，应重新论证，而不是把此等式当成任意随机控制问题的定理。它也不说明“无法研究因果控制”；它只限定可以从当前单条路径、当前策略集合和当前 oracle 合法声称的下界与 gap。
