# 升级实现待审草案

状态：基线复现尚未完成。本文件只记录需要在实现前解决的接口和实验约束，不是已完成模型，不包含升级计算结果，也不替代之后冻结的机器可读实验登记。

## 固定时域与合同边界

原 `legacy_two_midnights` 完整保留。新增固定核心时域以 `end=min(as_of+6*H,evaluation_end)` 定义，H 为小时。48、72、96 的比较保持原预测器、成熟块构造、反馈器、末值估计公式和每6小时重规划的时钟。

固定时域的非午夜末点仍有该日剩余合同。有限窗口的库存线性奖励是启发式末值，并不构成完整 Bellman 继续费用。若窗口内只显式优化未来日部分交付时段，应明确这只是尚未执行的未来合同规划截断；真实执行时每次0点仍签完整日合同。需要说明边界外合同的完成策略和没有计入窗口的后续费用，不可将该截断宣称为完整多阶段最优。

已有SDDP根割只在午夜、合同清空的状态上验证。它不能未经处理直接用于6/12/18点的末状态。接入前必须选定并验证以下一种途径：包含剩余原合同及有效合同的相位相关辅助值；或显式衔接至午夜并如实披露衔接段及费用。若尚未完成，已有SDDP只能在原午夜对齐对照中报告，不能假称已通过同固定H的末值消融。此项为未解决接口，不预选方便但不正确的替代。

## 可测外生状态

区分签约前信息与当前净负荷揭示后的电池信息。价格遵循上一版权限：当前结算价格不供当前动作使用，已经结束时段的价格可以用于预测。

固定价状态包括净需求误差及其指数平滑量。浮动价状态另外包括按披露滞后可知的价格误差及其平滑量。不能直接把当前未披露的真实价格误差放进状态。

历史状态、未来场景状态与实时状态必须使用相同误差参考、量纲、平滑更新和披露时钟。保存预测原点和观测可用时刻，避免用事后拟合残差代替当时误差。每次规划的未来价格实现属于随机变量，进入下一步的可见滞后价格状态，而不是让当前动作通过场景编号识别它。

考虑用物理隔离的信息视图强化这一约束：给上层的实测数组在 `index>=as_of` 处置为不可访问/NaN，官方预报只暴露已经发布的行；日历与题给固定分时电价允许完整暴露。电池函数单独接收当前净需求及已披露滞后价格。实际当前价格只在动作完成后传给计费器。缓存也需绑定信息截断，泄漏测试不能因为复用原始全数据缓存而失效。

多候选重复计算可缓存每个历史预测原点的最大前瞻轨迹，而非为每个W/S复制完整窗口。提取长度T的历史残差前缀仍要检查 `origin+T<=as_of`；未成熟的缓存后缀不得进入距离、方差、聚类、A矩阵或任何训练统计。预测缓存按原点只用当时可见输入生成；全年的缓存存在不表示当期有权访问未来原点。自动测试还要扰动未成熟缓存后缀，验证其不影响当前合同与动作。

## 条件经验场景

候选从完整成熟的多日历史预测残差轨迹构造，保留原长度约束。窗口请求数与实际成熟块数分开记录；不复制轨迹来伪造W56或S14的数据量。

条件距离仅使用当前已经可见状态与各历史起点状态，标准化尺度只从合法历史估计。核权重是一种经验条件分布估计，不表示噪声服从高斯分布。带宽、权重地板与零方差处理必须在正式回放前冻结并说明参数类别。

场景缩减使用完整净需求/价格联合轨迹的尺度化距离。加权k-medoids/PAM或前向质量迁移只能声称求得算法返回的代表集合，不能宣称全局最优缩减。代表概率按原经验质量归并，不应重新改成等概率。

至少区分原均匀抽取、无条件轨迹缩减、条件轨迹缩减，避免把缩减和条件化的收益混为一项。记录请求/实际W与S、权重有效样本数、运输距离、累计与峰值净需求尾部覆盖、价格尾部覆盖和运行时间。权重有效样本数不等于相关序列的独立样本量。

## 上层与下层接口

保留原上层及M0作为兼容路径。新的统一外生特征上层另设标识，不能在比较M0/M1时悄悄同时更换合同特征。

未来原合同使用对应午夜之前的状态，未来调约使用对应合法发布节点之前的状态；库存反馈可以使用当前已揭示净需求。实际0点合同在所有场景共享。原合同q一直保留到交付结算，不能被调整量r覆盖。

费用目标必须按代表概率加权，包括紧急费用、合同分段线性费用和末值。返回的名义未来合同使用同一权重。记录原合同、调整合同和库存反馈增益的触界比例及单位；价格特征标准化应避免净需求与价格量纲的差别使同一个增益界失去意义。

M0保留原三分位状态及原条件价格均值。增强M1拟合按6小时时钟共享的状态转移，创新采用历史经验残差。库存维度维持凸分段线性值函数；外生维度采用有限状态支点/聚类及非负局部权重，禁止高密度全维笛卡尔网格。

增强Bellman更新应分别处理当前已知净需求、当前未知价格的条件均值、未来可见状态的转移。用当期真实价格先分箱再选择均价仍属于泄漏。实际连续外生状态可用非负归一化权重组合库存凸函数，从而保持对库存的凸性；库存动作再经过同一个物理执行器。

一个待审的结构约束是只回归误差行，再由EMA定义确定平滑状态行。浮动价的观测状态按 `x=(epsilon_n,t,z_n,t,epsilon_p,t-1,z_p,t-1)` 排列。若净需求下一步误差和当前尚未披露价格误差分别为 `a_n x+u_n` 与 `a_p x+u_p`，则A的对应平滑行应为 `alpha*a_n+(1-alpha)*e_z_n` 和 `alpha*a_p+(1-alpha)*e_z_p`，创新为 `(u_n,alpha*u_n,u_p,alpha*u_p)`。不能四行独立拟合后仍宣称z严格等于EMA。联合经验创新保留净需求/价格关联。这里的误差参考预测与可用时刻仍须先在实现中统一。

在当前净需求已知、价格未知的风险中性一步成本中，可用条件均价乘以当前缺口函数；下一步价值还需对含延迟披露价格的联合状态积分。控制先于当前价格揭示，故不能分别对每个潜在当前价格先最小化再平均。

库存凸卷积可用经过等价性检验的本地编译内核加速，但不得用于替代正在原样复现的基线。加速版本需与原函数及独立小LP核对，包括边界、平坦斜率、重复折点、正负净需求和单调性。不能以加速之名更换控制策略。
