## 数值判据与元数据

轨迹逐元素判据为 `abs(new-old) <= 1e-6 + 1e-11*abs(old)`；JSON 数值为 `1e-5 + 1e-11*abs(old)`。独立物理残差阈值 1e-5；独立费用重算阈值 1e-4 元。所有阈值在完整重跑结果产生以前冻结，不因结果差异自动扩大。非浮点日期与索引必须完全相等。NaN 只可出现在未使用的发布记录位置，且新旧位置必须一致；轨迹 NaN 或任何无穷值均失败。

NPZ 压缩文件哈希不作为数值相等判据。哈希用于冻结输入/源码和报告证据绑定。运行耗时、工作进程完成顺序和输出文件哈希本身不要求重现。执行记录必须成功、任务数和身份完整、时间不得早于本轮冻结。
