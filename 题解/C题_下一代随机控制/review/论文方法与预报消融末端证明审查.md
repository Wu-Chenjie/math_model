## 一、条件修订及当前状态

2026-09-11 修订复核：PM-1 至 PM-4 全部关闭。新增附录已明确首个滞后价格种子、当前全场景共同初始化，以及当前发布节点 q/r 的可优化权限。未发现新的数值算法错误。下列保留最初发现及依据，关闭项以后文复核为准。

### PM-1：消元命题必须限定可行增量及费用前提（已关闭）

命题写“令增量为 Δ，即可按公式实现”，缺少功率域。令 \(M=5000/6\)，可行条件至少为

\[
-M/\eta\le\Delta\le\eta M,\qquad
1200\le E+\Delta\le10800.
\]

这里上限为 750 kWh，下限约为 −925.925926 kWh。仅在库存界内并不够；例如从 6000 增加 800 kWh，库存未越界，但需要充电 \(800/0.9>M\)。需把命题限定为可行 Δ，或直接用下一库存的物理区间表述。

“移除同时充放电不增加费用”的证明还需非负电价、免费弃电和本轮既定合同费用；“不加入循环奖励”不能代替价格条件。本轮实际/模拟正价格满足此前提。更准确的消元证明是：对同时为正的 c,d，令

\[
b=\min(c,d/\eta^2),\qquad
c'=c-b,\quad d'=d-\eta^2b.
\]

库存增量不变，动作均不增加且至少一个为零，净耗电减少 \((1-\eta^2)b\)。以减少紧急购电或增加免费弃电平衡，非负价格下费用不增加。由此得到给定 Δ 的规范动作及最小紧急电量。建议同时在统一物理约束明确写 \(q,r,e,s\ge0\)，与源码一致；不能只列 c,d 非负。

### PM-2：Bellman 动作域与执行器可达域不可混同（已关闭）

正文使用 \(\mathcal E(E)\) 却未定义。当前 DP 的连续动作域仅为

\[
\mathcal E_{\rm phys}(E)=
[\max(1200,E-M/\eta),\;\min(10800,E+\eta M)].
\]

实际执行器另与真实终点可达集合相交。若本次动作后剩 N 段，则为

\[
\mathcal E_{\rm exec}(E,N)=\mathcal E_{\rm phys}(E)
\cap[6000-N\eta M,\;6000+NM/\eta].
\]

不能把第二个集合直接定义为式中的 DP 动作域并声称匹配代码：DP 使用有限终端罚项，真实执行另作硬投影。正文已正确区分有限罚与硬可行性，只需补齐两个域及 N 的计数时点。库存网格节点计算和连续弦插值的限制已经写出，可保留。

### PM-3：问题一及评价索引需有明确边界（已关闭）

“问题一据此形成确定性 LP”尚未给出该问题自己的首末库存约束。建议至少补一句：题给单日数据上最小化普通购电费用，\(E_0=E_{144}=6000\)，不需要合同调约或紧急购电；可以显式取 \(r=q,e=0\)，并保留母线平衡、功率、非负与库存界。该表述匹配实际 Q1 求解器。

跨日主账单的求和范围也宜明确为二月至十二月，二月一日的初始 E 按共同设置取 6000；一月用于历史与开发，不应无依据地称该库存由一月轨迹自然继承。若沿用从一月一日开始的绝对下标，主评价初点为 \(31\times144\)，而不是把“334 日的 E_0”和“全年绝对原点 0”混用。可在正文统一重编号，但须说明历史预测原点和实际日期的对应，不将一月成本隐含到主账单内。

### PM-4：核心状态和合同特征还缺可复现定义（已关闭）

当前文字的时序方向正确，但 \(\epsilon,z,u,\phi,\rho_q,\rho_r\) 的联系主要依靠文字猜测。建议用一小段或附录补齐：

- 本原点误差 \(\epsilon^{n,(a)}_t=n_t-f_n^{(a)}(t)\)、价格误差同理；EMA 按 \(\alpha\) 递推。
- 原点种子来自昨日同槽短期误差账本；历史训练各用自身种子，当前情景共用当前种子。首个价格滞后项的锚点规则不要省略成“任意初始化”。
- 未来原合同 \(\rho_q(t)\) 为该日午夜，未来最终 r 的信息截止为对应合法发布节点；\(\phi\) 使用该节点净需求揭示前可测的特征。上一时段价格已披露时可以纳入，但不能使用本段净需求。
- 增强上层的特征按情景质量中心化；价格分量依合法历史尺度换算。若正文同时覆盖 legacy/state 两条上层路径，应明确是不同候选特征，不要把仅增强版本具备的价格状态归给所有候选。
- 联合创新对应“下一净需求误差、本段隐藏价格误差”；M1 下层保持名义未来合同。上层特征只需可测，无需宣称它是充分 Markov 状态。

这些定义已经在源码及此前接口审查中存在，补充不要求新模型。V 的单位为元，x 的分量有各自单位；符号表将场景概率、x、V 合列为“--”可以拆开注明，防止库存和价格尺度含义丢失。

## 三、旧预报消融统一终点：前缀证明仍适用

对旧固定两午夜、线性尾值 Markov 控制器，删去某次官方预报只改变外生预测函数，不改变规划末点、合同权限、真实终点或物理执行规则。若自由/固定终点两次使用完全相同的删减函数、历史数据、配置和确定性求解规则，则原证明可以逐点归纳沿用。

绝对日下标从一月一日 0 起，二月一日起点为 31。复用 332 日后，切点是第 363 日，即十二月三十日 0 点，最后复用日为十二月二十九日：

1. 在所有复用节点，旧 \(H=144(d+2)\) 至多为 \(364\times144<T_\star=365\times144\)。真实终点尚未进入上层 LP 或 DP 终端函数，线性尾值及预测历史完全相同。
2. 复用部分最后一个动作之后仍余 288 段。保证任意允许库存可达 6000 只需最多 7 段：最坏补能需 \(\lceil4800/750\rceil=7\)，最坏放电需 \(\lceil4800/(M/\eta)\rceil=6\)。因此额外全局终端可达域在整个复用前缀不活跃。
3. 从相同初始库存归纳，前缀每个合同、控制输入、动作及下一库存相同。到切点旧日交付已完成，本日尚未签约，上一日 q/r 无须跨入新日；该旧控制器的其他统计量在 0 点由相同外生历史重建，传入实际库存即可恢复。
4. 后缀调用仍以十二月三十一日结束为真正终点，并使用相同完整外生数据。先复现自由后缀，再仅加入固定 6000 终点重算最后两日，是对这个具体策略的合法复用。

以上整数日期和可达步数已由本地纯算术核对，未运行优化。证明不依赖被删除的是 6/12/18 点哪一个预报；但必须继续保留原 Q3 四次合同调整权限。它不能推广到新版固定 48/72/96 小时、不同尾值或依赖控制历史/隐藏缓存的任意策略。

## 八、M0 明确递推的有界静态核对

新增 F=P V 与组内加权“先最小化、后平均”的递推，与 WeightedMarkovDP 和旧 MarkovDP 一致。具体映射为：self.future[j]=P@v；同一组内固定其条件均价，逐个净需求样本调用 inf_convolution，再按组内归一化概率求和。均匀三组分支沿用旧控制器，非均匀分支使用 Sω 的转移伪计数；源码中旧 MarkovDP 和 inf_convolution 的实现与 baseline_frozen 对应函数一致。

最小化在样本平均内，表达当期净需求先被观测后才选择动作。价格则使用该粗组估计的条件均价，在动作前积分，并非读出该时段尚未披露的实际价格。在线先以实际净需求定位分位组，再对同一物理域、同一组均价和继续项最小化。组内只按均价计价、转移只依赖分位标签，是明示的统计近似；它并非保留所有组内价格—净需求依赖的精确原问题 Bellman 方程。

空组的 ids 回退全场景，用于当期净需求分布和均价；转移 counts 空行经平滑后为均匀的 1/K 下一组概率，并不重新用全场景转移计数。正文已补齐该限定，回退范围歧义关闭。末时段各组拥有相同末值，所以空转移对末值本身不产生额外差异。

本轮未发现 min/期望顺序、信息披露或符号公式错误。只做静态对照，未运行年度优化；论文浮动布局参数不纳入本次数学审查。
