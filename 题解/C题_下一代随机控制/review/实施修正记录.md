# 实施修正记录

以下为审查发现的实现问题及修正，不是策略收益调参。

1. 条件场景在仅一个成熟候选块时，以样本标准差的 `ddof=1` 产生 NaN。独立审查先复现失败，随后改为单候选时 `ddof=0` 并保留数值尺度下界；独立场景检查重跑通过。工厂与配置的 EMA 及融合参数另加一致性断言。
2. 新代码的“当前预测加历史残差”与旧代码的加减顺序数学相同但浮点求值次序不同。兼容路径恢复旧顺序，并直接调用旧仿射求解器，仅增添增益诊断返回值；合同和场景库存与冻结旧代码的两个控制检查均完全一致。原项目与原样复现源码没有修改。
3. 对非午夜规划末点，原本仅记录合同后缀完成规则。现在同时保存具体后缀电量、原点截止和零反馈规则，明确该后缀没有进入核心费用，不将此截断称为完整Bellman续期。
4. 新版回放在开始时捕获源码哈希，并在完成时确认未改变；运行中若修改源码将拒绝认证产物，防止用结束时的新源码标记先前执行的旧代码。
5. 数学审查发现M1原来的反向支持点更新未采用在线动作的非插值核平滑。停止新版开发进程，将未完成的一月M0记录和准确旧源码移入 `artifacts/rejected-development-v1`，不用于选型。反向更新现先以同一支持点核平滑转移与均价，再作凸卷积；在线与反向节点目标须重新独立核对。此前尚未运行M1开发比较或任何新版正式年度评价。
6. 正式登记第二版明确“现有基线”为两午夜M0、真正末库存6000，固定48小时另作时域单因素参照。此澄清发生在正式评价之前，未使用任何新版年度费用。第一版协议保留在上述存档目录。

上述修正均在正式年度实验开始前完成。现有独立检查范围及待审项以各报告为准，不代替最后的全年审查。
