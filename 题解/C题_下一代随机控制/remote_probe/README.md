# 远程CPU小型基准

不运行全年、不修改模型参数。使用4个已审查的一月LP，分别测单实例和8个独立实例并发。

环境应先对齐本机：Python3.13、NumPy2.4.1、SciPy1.17.1、HiGHS1.15.1。不能把macOS的vendor动态库或.dylib复制到Windows使用；需相应平台的安装包。版本不可用时先报告，不擅自改求解器。

运行 `python benchmark.py --workers 8`，返回生成的benchmark JSON。GPU不参与当前IPM路径。单次最优目标接近不等于控制策略完全相同；发现解差需进一步检查合同和短闭环。

该基准的并行批次包含进程启动开销，不直接当作全年加速倍数。不要据此改变1月冻结的统计参数。
