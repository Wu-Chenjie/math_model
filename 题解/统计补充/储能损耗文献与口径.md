# 储能损耗：文献依据与赛题口径

题面原句：“储能设备的充放电效率为90%。”来源：C题_跨日随机控制/inputs/C题.pdf。该句未分别注明单向效率和往返效率。

当前实现采用 eta_c=eta_d=0.9，库存递推 E_next=E+eta_c*C-D/eta_d。C、D是母线侧区间电量。忽略静置损失时，往返效率是 eta_c*eta_d=0.81。此为明确的模型解释，不能用文献证明题目必然要求此解释。

依据：
1. Brown T, Hörsch J, Schlachtberger D. PyPSA: Python for Power System Analysis. Journal of Open Research Software, 2018, 6(1). DOI:10.5334/jors.188. https://openresearchsoftware.metajnl.com/articles/10.5334/jors.188 。支持含充放效率、功率约束和静置损失的跨时段储能建模。
2. PyPSA, Storage optimization documentation. https://docs.pypsa.org/latest/user-guide/optimization/storage/ 。提供分离充电效率、放电效率和静置损失的库存平衡。
3. PyPSA-GB, Storage Systems. https://pypsa-gb.readthedocs.io/en/latest/tutorials/10-storage.html 。实现 round_trip_efficiency = efficiency_store * efficiency_dispatch *100。

文献支持模型结构和效率定义，不支持无条件指定这道题的单向数值。若按往返效率0.9解释并假设两向相同，应采用 eta_c=eta_d=sqrt(0.9)，须完整重算。尚未执行该效率敏感性实验，不给出其费用结论。

正文建议：“采用分别计入充、放电效率的储能能量平衡。本文将题给90%解释为充电和放电各自的转换效率。题面未给自放电、线路损耗及循环退化参数，主模型不额外引入这些因素。”
