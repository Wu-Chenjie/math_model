# 跨日控制交接入口

本轮交付：第二至四问去掉每日6000 kWh闭合的迁移设计、人工有限场景机制验证、可执行代码和独立审查。第一问保留题目要求的首末库存条件。论文由用户手工撰写。

已完成的设计与人工算例通过独立审查；原附件全年跨日回放和通用SDDP训练器尚未实现。不能把本例费用差、原综合优化评分或原年度节省率当作新模型年度结果。

## 阅读顺序

1. `设计交接.md`：状态、信息时序、凸计费、场景MPC、SDDP、现有代码修改位置和验收步骤。
2. `机制验证结果.md`：本地LP计算结果及适用范围。
3. `review/prototype-review.md`及`review/findings.json`：独立公式实现与审查结论。
4. `artifacts/prototype-results.json`：原始路径、动作、库存、费用、割和迭代结果。

## 复现

在本目录运行（Python 3.13，numpy 2.4.1、scipy 1.17.0；绘图另需matplotlib及Songti SC字体）：

```sh
python3 src/two_day_tree.py
python3 src/report_prototype.py
python3 review/check-two-day-tree.py
```

前两步生成计算结果、结果登记与图表；第三步以独立充放电变量和显式非预见性等式复核。独立检查器绑定当前人工算例，修改输入后必须同步重新审查。重新运行会更新执行耗时及文件哈希；当前审查哈希代表本轮冻结快照。

图表为`figures/跨日价值函数机制.png`和`.svg`。图中曲线来自程序计算，已检查PNG的文字、图例和边界显示。
