# 符号、参数来源与数值精度

本表补充综合建模计算交接，供手工写作。题目常数与人为近似参数应分别说明；后者不能写成题目给定或已经获得统计最优。

| 符号 | 含义 | 单位/范围 |
|---|---|---|
| t | 日内10分钟时段，0至143 | 无量纲 |
| s，S | 历史误差场景及数量 | 随可用历史变化，最多28 |
| L，G，n | 负荷功率、光伏功率、净需求电量，n=(L−G)/6 | kW、kW、kWh |
| p | 普通购电单价；第四问实际价用于结算 | 元/kWh |
| q | 0点承诺的逐时合同电量 | kWh，非负 |
| r | 当前生效合同；完整日输出中为最终执行合同 | kWh，非负 |
| c，b | 交流母线侧充电量、放电量；代码放电字段为d | kWh，0至5000/6 |
| e，w | 紧急购电量、弃电量；代码弃电字段为spill | kWh，非负 |
| E | 内部储存能量，SOC用电量表达 | kWh，1200至10800 |
| η | 单向充电、单向放电效率 | 分别为0.9 |
| δ | 下一时刻E减当前E | kWh |
| a，g | 仿射策略基准库存、误差反馈增益 | kWh、无量纲 |
| z | 从本次发布起点重置的净需求误差EMA | kWh |
| ω_s | MPC中按已观测净需求更新的场景权重 | 非负，和为1 |
| v_i | 综合策略的日内固定专家权重；代码使用weights/w | 非负，和为1 |
| V，J | DP继续费用、完整随机控制价值函数 | 元 |

统一能量约束为r+b+e−c−w=n，E_next=E+ηc−b/η。当前模型免费弃电、不能售电，紧急电量未额外设上限。组合策略中的专家权重v与弃电w不要在同一篇文字中混用符号。

## 极小周转项与经济最优性的准确表述

代码在LP目标中加入λ=10⁻⁷乘充放电变量之和。该项只用于数值选择，真实费用表不含它。它是单次正则化求解，不是先精确最小化经济费用、再进行第二次词典序优化。因此严格的LP最优结论首先针对含此项的目标。

令F为未加周转项的经济目标，P≥0为周转量，x_λ最小化F+λP，x*最小化F。在精确求解的同一可行集上：

F(x_λ)−F(x*) ≤ λ[P(x*)−P(x_λ)] ≤ λP_max。

仿射上层有2ST个充放电变量、每个上界M=5000/6；因此可取P_max=2STM。下层共同动作MPC可取P_max=2TM。在S≤28、T≤144时，程序计算的单次子问题保守界分别为0.672元、0.024元，另加求解器数值容差。实际消去同时充放电保持SOC且在正电价、免费弃电下不会增加经济费用。该界不是全年闭环策略的费用界，不能直接相乘得到年度最优间隙。

这些常数由src/parameter_bounds.py生成，证据为artifacts/tie-break-bound.json。实验性精确消元LP在小样本中比较了无此项的经济目标，但未替换年度主求解器。当前年度结果来自一致的主代码。
