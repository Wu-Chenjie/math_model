# C题综合控制增量计算

原题及已验收基线在上级目录，本目录独立保存新增设计、代码、回测、图表和结果表。主结果按1月开发窗口选择候选后固定运行；另有过去28日在线选择和凸组合。第一问沿用原确定性LP。

- `综合建模计算交接.md`：自动生成的结果、解释与手工写作交接。
- `无限算力下的统一模型与最优性边界.md`：更完整的多阶段模型及当前计算边界。
- `符号与参数来源.md`：符号单位、题目常数、近似参数来源和数值周转项的误差界。
- `实验预声明.md`：冻结的候选、参数、选择与评价规则。
- `src/`：控制器、仿真、验证、统计与导出。
- `artifacts/annual/`：六候选乘四种设置的年度完整轨迹及费用。
- `计算结果/`：主输出xlsx、CSV及每日在线选择记录。
- `计算结果/综合策略/`及`综合策略指定日期表.md`：每日选择和凸组合的完整轨迹、合同发布记录、费用与指定日期数据。
- `review/`：独立设计、代码、小算例及最终审查。
- `复现.sh`：本机完整执行命令；耗时依硬件和求解器而变。

需要上级项目中已验证的数据缓存和预测模块；对应字节副本保存在inputs/prepared和inputs/baseline-code，冻结时再次比对。原输入不修改。主计算Python使用NumPy/SciPy，原生HiGHS 1.15.1仅安装在本目录vendor；表格导出复用已配置的artifact-tool运行时。

“最佳”仅指明确策略类和数据口径下的比较。完整多阶段SDDP、跨日不闭合和当期实价反馈是尚未执行的扩展，不属于当前主结果。正式验收状态以本目录modeling-manifest.json和artifacts/acceptance.json为准，不能沿用上级项目原评分。
