# 综合优化实验预声明

本增量项目保持原题、输入数据、原方案结果不变。目标是在明确的候选集合中比较实际费用，不能保证未知真实分布下的全局最优。

候选集合：原共同轨迹SAA上层＋贪心；原上层＋条件均值MPC；因果仿射SOC策略上层＋该策略投影执行；因果仿射上层＋条件均值MPC；因果仿射上层＋共同开环场景MPC；因果仿射上层＋三状态Markov网格DP。

仿射策略特征：当前净负荷误差、从当前合同发布时刻统一重置0的误差EMA（系数0.2）；反馈增益按六小时块共享，约束在[-10,10]。决策时共同优化合同、基准SOC和增益。当前净负荷只在电池执行阶段揭示，合同不得使用。日末那一行特征清零，统一6000kWh闭合。未经投影的策略在历史场景上约束可行；实际投影次数和幅度必须披露。

MPC使用当前已观测净负荷和最近6个已观测值，对历史场景做软匹配，并混入20%均匀权重；当前以后的实际观测不进入计算。场景MPC未来电池路径在所有样本中共同，属于保守可实施近似，不能称为完整多阶段最优。窗口到当日末，不偷看后续实际合同修订。

DP使用当时场景构造每时刻净负荷三分位状态、相邻时刻状态转移、状态内经验净负荷分布和条件平均价格。转移计数加一个总量为1的均匀伪观测。此为近似Markov模型，价格未假定事前可观测。SOC默认321格，另比较641格。不能把离散模型解说成连续真实系统最优。

所有组合使用原历史预测、28日残差窗口、效率/结算/每日末SOC等同一口径；1月22至31日用于开发选择，2至12月顺序回测。新方案均未使用2至12月费用来调参。预先固定两种可部署选择器：1月开发费用最低的固定候选；每天从候选中选择前28个已评估日累计费用最低者，最初历史不足时使用全部已有开发日。后者只在0点选一次，全天保持，不把当天最优专家事后拼接成策略。

回测结束后可报告“回顾性最低费用候选”，但它与事前选择、因果在线选择严格区分。当前年度数据已用于上一版开发，新的比较属于该固定数据上的增量顺序回测，不能冒称另一个从未查看的新外部验证集。

所有候选初始/日末SOC一致，使每日专家反事实可独立重放。日内调整均按新控制器实际SOC重新优化；Q3在0、6、12、18点依次揭示预测和合同。第四问实际价格只用于费用结算，不作为控制输入。

重点指标：总费用、紧急购电、每日费用95%分位及最大值、弃电、SOC/功率/供需违反、投影次数与幅度、运行时间；另做未来扰动不变性、基线复现、网格加密及独立审查。任何后续修正必须有错误证据，不得为提高回测表现隐性修改规则。
