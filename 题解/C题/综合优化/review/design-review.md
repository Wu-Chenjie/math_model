# 综合优化的独立设计审查

审查对象：原始 C 题、已冻结基线代码与交接，以及“控制方案评估”中的分层 MPC、非 MPC 评估文件。此次只审查设计与信息结构，不修改基线，也不将新方案描述为已经完成回测。原方案 89 分不自动适用于新方案。

## 一、设计结论

建议按两个阶段比较：先固定合同发布过程，更换下层控制；再改进上层合同与因果电池策略的联合规划。确定性滚动 LP、有限状态随机 DP、原反馈都是可执行候选，实际优劣应由同信息、同结算、同初末库存的闭环结果决定。

主代理后续提出的**有限维因果仿射 SOC 策略 LP**比直接按有限历史路径展开的树更容易审计。建议优先实现它作为上层改进，保留共同电池轨迹 SAA 作对照；下层分别执行仿射策略本身、确定性 MPC、Markov 网格 DP、原反馈。改变上层和改变执行器应分别归因。

没有一种上述方法能仅凭名称保证成为本题完整随机控制问题的全局最优方案。可以证明的是规划子问题的最优性、离散/受限策略类内的最优性和物理可行性；实际方案可以称为“在预先定义的候选集与评价规则下表现最好”。

## 二、最高优先级：合同发布本身也属于信息

### D1：固定合同对比不能提前使用最终 r

问题 2、4-2 的整日 q 在 0 点已签订，可以完整提供给下层。问题 3、4-3 的 NPZ 字段 `r` 则拼接了 6、12、18 点以后才形成的调整结果。

**不得把整条最终 r 提前传给 0 点的 MPC 或 DP 价值计算。** 未来 r 含随后观测与基线控制器 SOC 的信息，提前读取即产生未来合同信息泄漏。旧贪心只读取当前时段 r，所以其原始重放没有这个问题；新预测控制会读取未来向量，风险不同。

可执行的固定合同对照是按 `releases` 快照逐次揭示：0 点只见 0 点 q；6 点后只见截至 6 点已发布的合同，依此类推。两次发布之间，未来优化使用当前有效合同，不预知后续调整。将基线合同视为外部给定的、按时发布的过程，是用于隔离执行器价值的实验；它不是候选控制器自身优化合同后的最终完整方案。也可锁定 0 点 q 全天，但必须标为另一实验。

Q3/Q4-3 新的完整策略需在各发布时刻用**候选自身实际 SOC**重算上层，不能继续拿基线 SOC 生成新合同。

### D2：合同决定和当前电池响应是两个信息阶段

沿用既有离散化约定，0/6/12/18 点的合同决定使用此前已发生的数据、当前 SOC 和刚发布的预报，不能看到尚未发生的当前 10 分钟区间实际平均净负荷；该区间电池响应在约定的当前净负荷揭示之后执行。第四问需同样规定当前现货价何时已知。

因此，日前 q 与每次当前调整 r 在当时场景间共用，而随后电池动作可以依当前揭示的净负荷变化。不要因为 q 共用就错误地强制所有后续已观察状态下的动作始终共同；也不要把下层已经观测当前净负荷的权限反向赋给上层合同。

## 三、有限历史场景为何可能过于乐观

### D3：形式上的非预见约束不等于合理的信息模型

在连续观测下，不同历史日的前一两个观测几乎总能唯一识别该条训练路径。按“完全相同的历史前缀”连接节点，会很早分裂到单样本节点，随后整条后缀在经验分布中已被确定。其代数非预见约束可能完全满足，也确实对这个有限支持的经验模型最优；问题在于**经验模型把历史日身份当成了真实世界中可识别的隐状态**，从而高估未来补救能力。这不应冒充真实未知过程的多阶段最优性。

若以后实现树，至少需：

1. 节点标签只由当前及过去的可观测特征形成，逐层嵌套，不能用整条未来路径聚类后在早期揭示类别。
2. 限制分支数与深度；监控每节点样本量、独立日期数和有效样本量 `(sum w)^2/sum(w^2)`。样本不足时停止分叉或回退到较粗条件分布，不能继续用一个训练日的后缀。
3. 在粗信息状态下保留未来条件创新：从多个历史日期的相应时间块重新抽取后续误差，或估计带收缩的 Markov 转移。重采样更多副本不增加独立历史信息。
4. 仅用此前数据选择状态划分、转移正则和最小样本阈值；对未来日期执行真正因果闭环回测。不能只比较树内最优成本。
5. 单列树内预计紧急费与随后真实紧急费、节点占用/熵、样本外误差覆盖与尾部费用；诊断早期节点迅速变成单路径的现象。

“每个场景第一步相同、后面整条后缀任意独立”的两阶段近似也有相同的提前揭示风险。可以保留为明确标注的乐观近似/对照，不得称作已经解决真实多阶段非预见问题。

## 四、对拟定因果仿射 SOC 方案的审查

令 `xi_t^s = n_t^s - mean(n_t)`，`z_t^s = rho*z_(t-1)^s + (1-rho)*xi_t^s`，拟定

`E_(t+1)^s = a_t + g0_block(t)*xi_t^s + g1_block(t)*z_t^s`。

共同决策为当前整段合同 q/r、截距 a 和增益 g；各场景 c、b、e 通过能量/SOC关系联系。每 6 小时共用一组两个增益，共 8 个参数。xi、z 以 kWh 表示时，g 无量纲；a 为 kWh。

该结构是因果的有限维策略类：动作只通过当前净需求及过去 EMA 响应，无法通过任意历史路径编号选取独立未来动作。给定场景数据后，SOC 表达式对决策变量线性，物理约束和期望费用均可写为 LP。

### D4：实现前必须固定的六个细节

- **初始状态和 EMA 共用。** 每次重新规划的当前 E 和 EMA 初值必须是当时已知、所有未来场景共用的值，或统一将 EMA 重置为 0。不能给不同训练日各自一个已过去的 EMA 前缀；这会让模型在根节点拥有现实中未知的历史标签。若保留 EMA，需明确残差相对哪次发布的预测定义。
- **终端只修改最后一行。** `a_143=6000`，且最后状态表达式的两个反馈特征置零，保证每场景精确终端。不要因增益按 6 小时共用而误把整个 18–24 点块的增益锁成零。
- **场景内硬约束不等于样本外硬保证。** 真实执行先计算仿射目标，再投影到当前一步物理可达区间与终端反向可达区间的交集。投影保证执行可行，但会改变未见样本上的策略映射。需报告投影频率、幅度、触发时刻和费用表现；不得说投影扩展也已经由原 LP 全局优化。
- **控制增益与过拟合。** 限制低维响应可减少历史身份识别，却不能消除过拟合。应检查增益规模及跨时间稳定性；必要时设置有来源的范围或正则，并只用过去数据选择。不能因为样本约束可行就任由极端系数在未见数据上频繁饱和。
- **样本 c/b 的独立变量不会自动产生新权限。** 给定相邻 SOC 差，母线侧最省电的充放动作可唯一恢复为正差/eta、负差×eta。正价且允许弃电时可解析去除同充同放；之后重新计算样本紧急量和费用。实际执行应使用同一恢复规则。
- **规划与执行器必须对应。** 如果真实下层执行仿射目标，训练场景内策略成本可与 LP核对。如果后来改用 MPC 或 DP，这是“仿射策略近似的合同规划+另一执行器”的组合，不能再把整套组合称为同一仿射类的 SAA 最优。

本方案的恰当最优性表述为：**在给定历史场景、固定信息特征和参数限制下，求得样本内可行的有限维仿射策略规划 LP 的最优解；真实因果执行的性能另行回测。**

## 五、MPC 与 Markov 网格 DP 的边界

### 确定性滚动 LP

每步把当前实际净负荷/已知当前价格放入首步，未来只用当时可得的预测；当前合同按 D1 揭示。只执行第一个动作。若窗口到午夜，严格闭合；窗口未到午夜，不应每次强制窗口末端 6000，而应使用终端可达区间及已定义的继续价值。继续价值不计入真实结算。

确定性未来模型有预测偏差，但其在线执行可以完全因果；不要把“模型没有随机场景”直接当成信息泄漏。相反，若把实际未来价格或最终调整合同传入预测窗口，即使只执行第一步仍然泄漏。

### Markov 状态/网格 DP

电池仅有一个物理状态，不代表随机控制问题只有一维。需要定义可观测的误差状态 z、时刻/发布时刻、未来生效合同及预测等条件量。只有给定这些量能确定未来条件分布时才是精确 Markov 状态；用少数误差分箱是可检验近似。

转移概率应从已完成历史日的相邻观测估计，按时段/发布版本匹配，并对稀疏转移做收缩或合并。第四问尽量联合刻画净负荷误差与价格误差，避免把高缺口与高价格拆开后低估成本。不能用全年测试数据预先估计转移。

给定时刻和误差状态，若继续价值在 SOC 上按分段线性插值，一步动作可以用下一步 SOC x 表示。枚举以下落在可行域内的候选点即可精确求解该**近似继续价值下**的一步分段线性目标：可行区间端点、价值函数网格折点、`x=E`、紧急量从正变为零的折点。不得只四舍五入到最近网格而遗漏功率/终端边界；终端6000、实际当前状态和可达端点需可表达。

至少比较两到三个 SOC 网格精度及误差状态数，检查真实费用和动作变化。网格 DP 的“最优”限于该离散转移模型，不能用 DP 名称证明真实未知过程最优。合同更新后必须刷新依赖该合同的价值表，不能沿用旧合同的精确价值之名。

## 六、建议的比较与审查顺序

| 层次 | 合同 | 下层 | 目的 |
|---|---|---|---|
| 固定发布过程 | 原合同快照按时揭示 | 原反馈、确定性MPC、Markov DP | 隔离控制机会成本的价值 |
| 新上层 | 因果仿射SOC规划 | 仿射目标直接执行 | 核验所规划策略与实际执行对应 |
| 组合 | 同一新上层 | MPC、DP、原反馈 | 评价替换执行器的增量收益 |
| 可选树 | 同因果权限的受控分支树 | 配套因果策略 | 检查是否优于低维策略且没有路径识别乐观性 |

每组先保留每日6000闭合、相同主结算和2–12月334日，固定比较信息。跨日终端优化、风险厌恶、不同退款口径另列实验。外网无限额紧急补购保证供电可补偿，不能把零未供电当成低费用或强鲁棒性证据。

除真实总费用及分项，应记录紧急电量/峰值、弃电、SOC/功率/递推残差、合同发布冻结、规划值与实际值差、投影与失败回退次数。允许大计算成本不等于无需记录计算量；主要用于判断收敛和解释复现。

增加一个同初末SOC的固定合同完美信息下层 LP，作为电池控制的乐观成本参考。Q3 若使用最终 r 或实际未来价格，只能在该参考中明确标注为完美信息。任何因果控制成本不应低于相同约束和合同下的精确乐观参考（除数值容差）。

## 七、“最佳方案”及验证纪律

不能用同一334日反复选择窗口、网格、增益和控制器后，把最终赢家的该段成本再称作无偏样本外证明。可以采用1月固定开发选型，或每次只用过去日期的嵌套顺序选型；若计算后选择全年最佳固定候选，则如实称为这份历史评价集上的事后最好，并另给严格顺序选择策略的结果。

最基本的反例检验是：保持测试时刻已知信息不变，改写其后实际负荷、光伏、价格、尚未发布预报和尚未发布合同，当前决策必须不变。改变**已经用于拟合的历史场景**会合法改变模型，不能混同于测试轨迹的未来信息检验。

当前设计审查结论：同意推进低维因果仿射上层与MPC/DP/原反馈的分层比较，D1–D4必须在实现中逐条落实。新方案最终优劣、正确性验收和分数均待代码及计算产物后再作判断。
