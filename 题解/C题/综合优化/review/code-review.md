# 综合优化核心代码阶段审查

范围：`src/controllers.py`、`src/run_comparison.py` 与实验预声明。未改动基线或生产代码。此次是代码和短算例审查，**不是全年产物最终通过判定**。

## 核心结论

未发现当前核心方程中的阻断性错误。仿射 SOC LP、共同开环场景 MPC、Markov 网格 DP 在各自声明的近似信息模型下结构一致。独立短算例已执行，证据见 `controller-small-checks.json`，复核入口为 `python3 review/check_controllers.py`。

### 仿射策略

变量切片、SOC递推、场景母线供电约束、共享合同及调整正负部分均核对一致。截距和反馈增益共用；当前误差与EMA只在实际电池动作中使用。每次发布时EMA统一重置0，最后一行反馈特征归零，未错误地锁死整个最后六小时块。

独立对0/6/12/18四个发布起点，用7条人工场景逐条执行返回的仿射策略，费用与LP返回的去除同充同放后费用差不超过9.1×10⁻¹³元，最大投影约1.82×10⁻¹² kWh，末端误差为0。该检查确认训练场景中的规划策略确实可以按所写因果映射执行。

### MPC

当前观测只用于已发生前缀的后验软匹配及首步净负荷；未来没有读取实际净负荷或实际价格。场景版所有未来电池动作共同，紧急购电按场景变化，故没有把未来场景专属电池路径伪装成多阶段反馈。每次只执行首步SOC，随后重算。

在人工三时段例中，第一段电价0.4、第二段1.4、两段各缺100 kWh，第三段有恢复SOC的固定合同。确定性和共同场景MPC均正确选择第一步保留电池，目标SOC为6000 kWh，而非机械地先放电。

### DP

实现的Bellman顺序为：给定当前离散状态，先观察该状态内当前净需求发射值，再最小化当前动作，随后对发射值求平均；继续价值按状态转移求条件期望。这与当前净负荷已观测的权限一致，没有把未来发射样本置于当前最小化的信息集。

独立使用另一种递归枚举实现，在3步、4条路径、33个SOC格点上逐状态比较，有限值区域完全一致，最大价值差为9.10×10⁻¹³元。此为所声明离散近似模型的核验，不是现实未知过程最优性证明。

## 全年结果到位后的验收重点

逐方案独立重算实际费用、能量守恒、SOC/功率/终端约束、合同发布时间边界，以及原基线是否精确复现。检查仿射投影频率与幅度、网格加密结果、两种预声明选择器的历史索引和选型因果性。固定候选的回顾性最好、1月选定候选与按过去28日选择的可部署策略须分列。

不得把仿射LP的`objective_after_cancellation_gap`误称为对偶最优性间隙；它包含周转正则与互斥转换的差。`MarkovDP.max_bellman_residual`当前只是未更新的初始字段，不能把该字段的0当作Bellman残差证据，本次有效证据来自独立递归枚举。完整运行失败时应保留异常记录，不把未完成候选当作通过。

阶段决定：允许继续全年计算与对照，待冻结全年产物后再做最终审查和评价。
