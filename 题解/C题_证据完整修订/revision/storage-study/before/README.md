## 固定主配置与数据入口

主稿采用第二个午夜为末点的滚动规划：0、6、12、18时实际前瞻48、42、36、30小时；成熟历史28日，等权场景7条，库存网格321，三箱Markov反馈，线性末值。日内机制采用已发布官方预报（融合权重1）。正式评价2025年2月1日至12月31日，334日、48,096段，真实初末库存均6000kWh。

四机制主费用依次1,384.42、1,346.18、1,465.46、1,425.21万元。主比较为同终点跨日贪心，节省20.24、23.13、15.29、22.89万元；三种块长区间均为正，11个月累计均为正。本文不把主策略与每日闭合贪心的差额归因于单一跨日权限。

本目录`revision/base-artifacts/q2.npz`等四份文件为固定真实终点的完整主轨迹。根`artifacts/q*.npz`是保留的自由终点历史文件，不能用来导出本稿主结果。重新生成时从相邻`C题_跨日随机控制/artifacts/global-terminal/`读取固定终点轨迹。

“调整购电量”工作表的逐段值是最终有效合同r，不是增量r−q；发布过程另存调整发布记录CSV。实际费用包含合同、增购、退购净额与紧急电。

## 下一代配置的研究位置

固定48/72小时与融合矩作为诊断单独报告，不替换主配置。48→72小时在四机制分别节省2.57、−1.13、6.12、0.81万元。问题二的2.62万元增量与跨零区间同时报告。融合样本最优权重0.8341/0.7617说明误差互补，但不是无偏留出结论，也不是账单最优权重。

远端72小时+0.75的三个机制缺少本地原始轨迹，未纳入本稿摘要、主表、指定日期结果或工作簿。非午夜合同继续价值的独立误差尚无匹配反事实，未赋予数值。它们属于另一候选升级的待核验事项。
