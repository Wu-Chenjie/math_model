# 可用容量与全年库存：实验定义

本实验固定主策略、两午夜规划、7条场景、28日成熟历史和真实初末库存6000 kWh，只改变以6000为中心的可用库存区间。运行期2025-02-01至12-31，334日、48,096段；1月公共初始化不进入容量账单。

所有容量保持5000 kW母线功率、每向效率0.9、原始附件、预测器与预报权限、成交规则、末值倍率和终点不变。窗口缩小时不重新选择参数。W为可运行库存范围，不是额定电池容量；本实验不研究电池投资、折旧或容量配置最优。W0表示停止使用库存调节，绝对库存保持6000，单向执行器动作必为零。

8个新容量机制组合分别在独立操作系统进程运行，进程内同步改变原LP、MarkovDP和执行器读取的边界。线程池仅发起独立进程。每组合同与动作均重新闭环生成；W9600采用论文已验证主轨迹，另用真实年末两日后缀核对包装器默认配置是否一致。全部结果独立重算结算、供需、库存、功率、互斥及终点；不得用裁剪旧库存代替重算。

主表报告三个容量点完整现金费用；补充报告分项费用和配对日差的7日移动块区间。零窗口至全窗口、半窗口至全窗口分别定义差值，10000次，seed20260912，区间只作当前单年度时间稳定性诊断。三点不直接证明边际收益递减。集合包含关系保证同模型精确最优期望费用不增，不保证具体近似控制器的年度账单排序。

全年可视化独立展示365日原主库存，1月为公共因果初始化，2—12月为正式主轨迹；热图逐十分钟段末值，折线连接366个午夜边界，色带为每日145个边界状态的范围。两图分别承担日内时序结构与跨日连续性的论证，不赋予额外节省。
