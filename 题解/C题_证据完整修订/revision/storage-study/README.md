# 可用容量消融与365日库存证据

这里保存论文新增两项实验的程序、实际运行结果及独立核验，不修改原控制器或主结果工作簿。历史稿存于 `before/`。

## 固定实验口径

正式期为2025年2—12月334日。初末库存6000 kWh、功率5000 kW、每向效率0.9一致；可用窗口W取0/4800/9600 kWh，区间为以6000为中心的宽度W。正窗口网格间距30 kWh；零窗口为停用动作的单点分支。W表示已有电池开放的运行空间，不是额定容量选型。所有窗口采用原主策略，两午夜时域、7场景、官方预报权重1，不在评价期重新选参数。

8个新组合重新规划全部合同、执行全部动作。9600使用 `../../revision/base-artifacts/` 中四机制原固定终点主轨迹，并重算各自真实年末两日用于逐变量一致性检查。正式结果与旧根目录的自由终点轨迹不可互换。

## 文件职责

- `run_capacity.py`：单个机制和窗口的真实全年回放；调用同级原题解源码，仅在独立进程内替换各模块共享的物理边界。
- `run_batch.py`：8个独立进程的批运行。线程池只启动进程，模型全局变量不在线程间共享。
- `results/`：每组完整NPZ、配置与逐日账单JSON、运行日志；含四组基准末端复演。
- `verify_capacity.py`：不导入生产控制代码的独立物理、信息权限与账单核验，并生成7日块重采样结果。
- `capacity-audit.json`、`summary.csv`、`daily-costs.csv`：最终独立审计、12组汇总和逐日分项账单。
- `inventory_figures.py`：拼接共同因果一月初始化和正式主库存，逐段核验后生成热图与午夜折线。
- `annual-inventory.npz/json`：365日边界库存、366午夜状态、统计定义与残差。段末触界次数/比例不是持续触界时长；零窗口上下界重合，两类命中统计对应同一批采样点。
- `zero_window_quantile.py`：把零窗口日前合同退化为价格加权0.8分位数规划，独立核对同场景目标值。
- `build_storage_evidence.py`：只读取审计PASS结果生成容量图、LaTeX表与定量结果文字。
- `experiment-design.md`：实验边界；`start-snapshot.json`及核验观察快照记录执行中观察的哈希，不冒充正式预注册或启动时监测。

## 重现

保留同级 `C题_跨日随机控制`，其输入、原源码与固定终点轨迹不可缺少。Python需NumPy、SciPy、HiGHS、Matplotlib，中文图使用系统黑体。所有主核心源码与论文打印副本一致。

在论文目录执行 `sh reproduce.sh check`：独立核验保存结果，重建图表并编译论文；不会重新运行8个年度求解。

执行 `sh reproduce.sh capacity`：先重算四组基准后缀，再运行8个新容量年度组合，之后执行同样核验与排版。此命令会更新本目录结果，运行时间由机器和并发负荷决定。各组合保留独立退出码和实际耗时。

容量收益与固定容量的算法改进使用不同对照，不能相加。未提供投资、退化和容量功率配比数据，不给额定容量投资最优或回收期。三点费用连线只连接已计算点，不拟合未执行的容量表现。
