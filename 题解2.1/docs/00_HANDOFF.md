## 3. 模型（最终版，全部LP，无整数变量）

### 3.0 统一记号
时段 t=0..143；决策：购电 p_t≥0、充电 c_t∈[0,833.33]、放电 d_t∈[0,833.33]（kWh）；S_t 时段末SOC∈[1200,10800]。
平衡：`p_t + PV·Δt + 0.9·d_t ≥ L·Δt + c_t`（缺供→紧急购电5π；过剩→弃光无成本）。
SOC：`S_t = S_{t-1} + 0.9c_t − d_t`。执行SOC由计划c/d确定性递推（计划可行⇒截断恒不触发，validate零违例实证）。

### 3.1 P1：单日确定性LP
min Σπ_t p_t，S(0)=S(24:00)=6000。同时充放由交换论证排除（纯LP充分）。

### 3.2 P2：逐日两阶段SAA随机规划（核心方法）
- **预测**（仅0:00可得）：负载=上周同期 L[d−7]（MAPE 3.96% vs lag-1 15.97%）；光伏=近3日均值（MAPE 6.42% vs lag-1 7.70%）。
- **场景**：K=15个"实际−预测"误差样本（最近15天）叠加基准预测，截断非负。
- **计划LP**：`min Σπ p + 5·Σ_k w_k Σπ e^k`，场景平衡约束，日末SOC=日初=6000（日循环，INN-1命题：日不变价+往返0.81<1 ⇒ 跨日储运弱次优，计划层零损失）。
- **执行（v3 实时反馈 `feedback_execute`）**：购电量 p 按计划执行；逐时段观测实际净负荷，电池优先吸收偏差（富余→充电、短缺→放电，受功率/SOC约束）；每步将SOC投影进"距日末可达带" `[max(1200, 6000−R·750), min(10800, 6000+R·833.3)]`（R=距日末步数，归纳保证日末精确=6000）；残余缺口→紧急购电（5π），富余→弃光（免费）。1月为warm-up（跑不报）。

### 3.3 P3：P2框架 + 光伏用附件3的0:00预报 + 6/12/18时滚动调整
- 0:00计划：光伏=附件3的0:00预报曲线（fc0），负载=lag-7，SAA场景。
- 调整LP（τ=6/12/18 → t0=42/78/114，钟点7:00/13:00/19:00起）：`min Σ[π p_t + 0.5π u_t] + 5Σw_kΣπ e^k`，u_t≥|p_t−p_plan,t|线性化；**以实际SOC为起点 + `intraday_correct`（当天近6h实际−预测均值平移修正剩余时段负载预测）**，日末=6000。
- 计费：`总费用 = Σπ·p_final + 0.5Σπ|p_final−p_plan| + 5Σπ·E`（与题文"超出1.5π/不足罚0.5π"代数等价）。
- 各调整段执行同 `feedback_execute`（投影目标6000；**第一段[0,42)也须执行反馈**——曾漏执行被validate抓获）。
- **是否需要其他时刻预报（题目问）**：需要。三臂+子集消融（paper_tables.json `p3.adjust_ablation`）：
  A(仅0:00)=1438.6万 → {12}调整=1424.4万 → {6,12}=1413.9万 → {6,12,18}=1401.3万（C无调整=1424.2万）。
  **边际价值：12:00单独≈0（比C还贵0.03万，被6:00覆盖）；6:00贡献10.6万；18:00贡献12.6万**。
  B比A省37.3万(2.6%)、比C省22.8万(1.6%)；紧急费由43.1万压至7.2万（em_max 48,743→4,472元/日），代价为违约费38.7万。
  论文表述建议："调整的核心价值是风险压缩（紧急费−83%），收益主要来自6:00与18:00两次修正；12:00单独调整无增量——其可修正的午后不确定性已被6:00决策大部分覆盖"。

### 3.4 P4：波动电价 + 两日滚动
- P4-2/P4-3 = P2/P3框架，电价换附件4；**窗口改两日**：每天解[d,d+1]两天LP（今天带15误差场景、明天点预测；今天日末SOC自由、明天日末=6000），执行今天，SOC结转，明天滚动重优化（相邻日价差可超往返损耗 ⇒ 跨日套利）。
- 执行层：P4-2 反馈**不投影**（窗口末SOC由次日滚动重解承接）；P4-3 调整LP与反馈均**锚定当天计划末态 S_plan_end**（保留跨日套利结构；⚠️若末态设None，LP会短视抽干电池退购套违约退款，违约费暴增至84万——已修复）。
- 明日光伏预测合规化：`pv_fc_tmr(d)` 仅用 d−1 及更早实际（避免混入d日当日实际，G3-8修复）。
- **假设A-P4-1（论文必须声明+敏感性防御）**：D日0:00已知未来48h电价曲线（题面仅言"实时波动"未说未知，此为标准做法；第三方题解采用更严的历史电价预测口径）。
