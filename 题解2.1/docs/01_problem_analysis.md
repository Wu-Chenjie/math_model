# C题 微网与外部电网电力调控策略 — 问题分析与数据字典

## 1. 赛题结构

微网含：光伏发电、储能设备、小区负载，与外网相连。目标：制定购电+储能充放电策略，
满足负载的前提下最小化购电费用。

## 4. 各问题要求映射

### 问题1（代表日，确定性）
- 输入：附件1（电价π、负载L、光伏预测PV均为已知曲线），储能初值6000
- 约束：① 每时段 供电 ≥ 负载；② SOC(0:00)=SOC(24:00)=6000；③ 储能SOC/功率/效率约束
- 输出：表1（10:00-10:10等6个时段购电量+全天购电量+购电费）、表2（6个4小时段充/放电量+0:00/24:00储电量）、result1.xlsx

### 问题2（全年逐日，负载/光伏随时间变化）
- 电价：附件1分时电价每天相同
- 每天0:00制定计划：信息集 = 当天0:00前可得数据（历史实际）
- 执行：购电按计划量执行；充放电按计划执行；实际供电 < 实际负载 → 紧急购电（5倍电价）
- 输出区间：2025.2.1–12.31（1月作warm-up）；表1/2/3格式（指定日期：3.20, 6.21, 9.23, 12.21）、result2.xlsx

### 问题3（全年逐日 + 4时刻预报调整）
- 0:00用附件3的0:00预报制定计划；6:00/12:00/18:00用最新预报**调整**后续时段购电量
- 计费：总费用 = 计划购电费用 + 紧急购电费用(5π) + 调整费用
  - 调整后购电量 > 计划：超出部分 1.5π；< 计划：不足部分 0.5π（违约金）
  - 代数化简：费用 = Σ π·p_final + 0.5π·|p_final − p_plan| + 5π·E_emerg
- 分析问题：是否值得引入6:00/12:00/18:00预报调整（对比仅0:00预报方案）

### 问题4（波动电价）
- 电价换成附件4（每天不同、10分钟级波动）；重算问题2 → result4-2.xlsx；重算问题3 → result4-3.xlsx
- 计划时点电价信息：假设0:00已可知当天电价曲线（题目未给电价预报，为标准假设并在论文说明）

## 5. 统一记号

- Δt=1/6 h；时段 t=1..144；π_t 电价；L_t 负载(kW)；PV_t 光伏(kW)
- 决策变量（每时段）：p_t 购电量(kWh)、c_t 充电量(kWh，储能侧充入前)、d_t 放电量(kWh，储能侧放出)、S_t 储能量(kWh)
- 能量平衡（供电≥需求）：p_t + PV_t·Δt + 0.9·d_t ≥ L_t·Δt + c_t
- SOC递推：S_t = S_{t-1} + 0.9·c_t − d_t；1200 ≤ S_t ≤ 10800
- 功率限制：c_t, d_t ≤ 5000·Δt = 833.333 kWh

## 6. 建模路线（lead草案，待modeler审查）

**P1**：标准单日LP，min Σπ_t p_t，SOC(144)=6000。≈450变量，CBC秒解。

**P2**：逐日滚动LP（1.1起跑，1.1计划用附件1曲线，其后用前一日实际作naive预测）；
日末SOC约束=SOC(24:00)=SOC(0:00)（每日完整循环，可复现、避免透支未来）；
执行仿真：购电/充放电按计划，缺口→紧急购电5π，光伏过剩→弃光。
对照基准（论文加分）：全年联合LP（52560时段）作为理论下界，量化逐日策略的最优性gap。

**P3**：0:00计划同P2框架（光伏预报=附件3的0:00预报，负载=naive）；
6:00/12:00/18:00滚动重新解LP（从当前时刻到24:00，SOC取计划轨迹值），
更新后续购电量与充放电计划；费用=Σπ·p_final+0.5π|p_final−p_plan|+5π·E；
对比"仅0:00预报"与"加入调整"的全年总费用，数值回答"是否需要引入其他时刻预报"。

**P4**：P2/P3模型不变，电价序列替换为附件4；逐日LP目标用当天波动电价。
（P4-3中违约/上浮电价基数=交易时刻的波动电价）

## 7. 风险与待审查点

1. 日末SOC回归约束 vs 全年自由SOC：是否显著次优？（用全年LP对照验证）
2. P2负载/光伏预测用前一日实际（naive）：是否有更优且0:00可得的选择？
   （可做：滚动周均值、指数平滑；在敏感性分析中比较）
3. P3调整时刻的重优化是否会造成"计划-调整-再调整"的反复振荡？（每次调整覆盖后续全部时段即可）
4. 紧急购电发生在充电同时段的处理：计划充电照常执行，缺口全部由紧急购电补（题意）；
   或执行时优先暂停充电（更现实）。默认按题意：充放电严格按计划。
5. 弃光无成本、售电不允许（题目未给售电机制）。
