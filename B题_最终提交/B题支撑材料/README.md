# B题几何策略优化（支撑材料）

针对2026年国赛B题（无线电干扰源的快速自动定位与清除）的模型、控制器与可复现实验包。

## 结论速览

- **推荐默认：方法78**（`joint`，规划深度2）；**实验候选：方法84**（`geometric`）。
- 候选84在独立集Q4上相对方法78平均节省28.41秒（0.496%），95%区间 `[-5.92, 62.75]` 跨零、200局中86局更慢，按预声明规则**不予推广**。
- Q3与方法78逐局相同；其对方法56的1.48秒（0.049%）收益全部来自既有的安全提前停车。
- 六次官方演练全部清除（82/82，比例100%）；六次正式测试合计清除74个、HTTP错误0、均主动退出。
- 方法编号索引见论文表2；列明配置继承关系和组合改动。

## 目录

- `inputs/` 原题与所附论文格式规范。
- `src/` 在线机器人（`robot.cpp`+`policy.hpp`等）、几何、控制器、证书与实验分析。
- `tests/` 27个C++回归程序与6个Python核验脚本。
- `review/` 认证布局（21点双环的二进制64位坐标）。
- `vendor/mocksim/` 依据公开协议实现的本地模拟内核，**不是官方模拟器**。
- `results/` 开发、独立验证与压力测试逐局CSV；不含参赛队号明文日志。
- `artifacts/` 冻结配置、执行命令、哈希、区间统计、几何证书与复核结果。
- `supplement/count_time/` 源数量--单源均时的**经验**拟合、冻结新样本验证与图表。
- `supplement/count_time_theory/` 源数量--平均时长的**一般关系**（代数判据、BHH结构模型、TSPN下界）与有理数核验。
- `paper/`、`figures/` 论文LaTeX源码（入口 `main.tex`）、自动生成数表与图。
- `official-logs/` 六次正式测试从官方模拟器导出的加密 `.jlog` 原件，文件名未修改。
- `AI工具使用详情.pdf` 按2026年试行规定编制的AI使用说明（文件名与规定原文逐字一致）。
- `PACKAGE_HASHES.json` 包内全部文件的SHA-256清单。

## 运行方式

在包根目录执行：

```bash
python run_all.py          # 编译C++目标、重建总览图、运行核心回归与证书
python run_all.py --full   # 另重跑固定独立集与压力集（耗时较长）
```

需要Python 3、C++17编译器（`g++`/`clang++`，可用 `CXX` 指定）与 `requirements.txt` 依赖。
`python run_all.py --paper` 另从冻结CSV重建五幅图、完整源码附录与两份PDF；保留经过核对的论文表格。需要 XeLaTeX（含 ctex、Fandol 字体）。默认入口运行核心回归子集，不等同于运行全部27个C++测试程序。

在线连接官方模拟器时，队号由操作者通过命令行参数临时输入，不写入源码或本支撑材料。

## 复现边界（务必如实表述）

- 本包保证：源码可编译、回归与证书可重跑、结果CSV与论文数表一致、哈希与匿名性可核验。
- **没有**重跑全部2000余局模型实验，**没有**重跑官方正式测试（正式成绩为官方模拟器导出记录）。
- `run_all.py` 默认只重建证书与回归，不重跑实验集；历史CSV不参与任何配对或合并。
- 本地场景含40米源间距排斥，与官方未知分布不同；论文统计结论仅适用于该公开的本地分布。
