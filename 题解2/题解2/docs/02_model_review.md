## ① 风险点裁决

### R1（草案7.1）P2"日末SOC=日初SOC" vs 全年自由SOC

**裁决：P2采用日末循环约束，且可以证明它在P2条件下不产生计划层最优性损失；P4必须放宽。判据给出如下。**

**命题（跨日储运弱次优）**：若电价满足日不变性 π_{D,t}=π_{D',t}（P2/P3由附件1保证，核查：price1 全年同一条曲线），
往返效率 η_rt = 0.9×0.9 = 0.81 < 1，且 SOC 约束为逐时刻局部约束，则在计划层任意跨日净能量转移都可被逐日循环解弱费用替代。
证明梗概（交换论证）：设最优解中某日 d 净充入 δ>0 并在后续日期释放，替代购电 0.81δ kWh，同价购买，
费用净增 (1−0.81)πδ > 0；若不释放则属一次性消耗初始 6000 kWh 的瞬变，仅发生在 年初。δ<0 情形对称。
故全年联合LP存在"1.1一次瞬变 + 此后逐日循环"结构的最优解。∎

- **适用域（regime of validity）**：(i) 日间电价不变（P2/P3成立）；(ii) 计划层（紧急购电是执行层现象，不进入本命题）；
  (iii) 无跨日耦合约束。**P4失效**：附件4日均价范围 0.538–0.929 元/kWh，相邻日均价差绝对值均值 0.0616，
  极端日间价差(~0.39) > 往返损耗成本(~0.19×0.77≈0.15)，跨日套利有利可图，故 P4-2 必须放宽日循环（见P4规范）。
- **判据（数值证书）**：以全年联合LP（完全预见下界，见第②节B）为基准，要求
  gap = (P2执行总费用 − 下界)/下界。计划层命题预言 gap 全部来自执行层（5π紧急费 + SOC截断）。
  若 gap ≤ 2%：接受日循环并引用命题解释；若 gap > 2%：检查执行规则与预报器，而非放开日循环
  （放开日循环在P2条件下由命题知无收益，只会引入短视透支风险）。
- **附**：短视单日LP若放开日末SOC（自由末态），因目标不含次日价值，最优解仍落在 S(24:00)=S(0:00) 附近
  （多买不放电纯浪费π），即"日循环 vs 自由末态"在P2的滚动框架内实质等价——这是判据的第二个支撑。

### R2（草案7.2）P2 用前一日实际作负载/光伏预报（naive lag-1）

**裁决：负载 lag-1 是错误选择，必须更换；光伏 lag-1 可改进。数据证据（评估窗 2025.2.1–12.31，MAE, kW）：**

| 预报器 | 负载 | 光伏 |
|---|---|---|
| lag-1（前一日实际，草案方案） | 650.0 | 185.3 |
| lag-7（同星期上周） | **176.8** | 214.7 |
| 近4个同星期均值 | 188.9 | 251.7 |
| EWMA(α=0.3) | 592.9 | 162.0 |
| 近3日均值 | 945.1 | **154.5** |
| lag-1与lag-7各半 | 372.3 | 172.0 |

- 负载具强周周期：lag-7 比 lag-1 误差小 **3.7倍**。**P2负载预报器定为 lag-7**（前7日不足时用可得历史的同星期均值退化）。
- 光伏最优为近3日均值（3日均 154.5 vs lag-1 185.3，降17%，含季节漂移跟踪）。**P2光伏预报器定为近3日均值**。
- 最终选型判据：以"完整P2流水线的年执行总费用"终审（MAE只是预筛，误差发生在高价放电窗的代价不同）；
  coder须跑 {lag-1, 主方案}×{光伏lag-1, 3日均} 的 2×2 组合并报告年费用，确认主方案胜出。
- 全部候选均只使用 D 日 0:00 可得信息（附件2截至 D−1 24:00 的实际值），信息集合规。

### R3（草案7.3 + 任务指定）P3 调整时刻重优化的信息集与计费口径

**裁决：草案的计费口径正确，予以确认并补全三处精确定义；另发现草案一处缺失（重优化目标必须内嵌调整惩罚），见③-2。**

1. **信息集与执行量定义（确认草案）**：计划购电量 p^p_t = D日0:00依附件3的0:00发布制定的计划；
   调整购电量 p^f_t = 该时段最后一次调整后生效的执行量（时段 t<37 恒等于 p^p_t）。
   附件5模板将"计划购电量"与"调整购电量"分为两张同构sheet，且题干罚则只对照"计划 vs 调整"两方——
   **中间历次修订（6:00改了、12:00又改）不叠加计罚，惩罚每时段只算一次、以 |p^f_t − p^p_t| 计**。草案理解正确。
2. **计费公式（代数确认）**：题文三种计价——按计划量与执行量取 π、超出部分 1.5π、不足部分罚 0.5π。
   超出：π·p^p + 1.5π·Δ⁺ = π·p^f + 0.5π·Δ⁺；不足：π·p^f + 0.5π·Δ⁻。两式统一为
   **费用_t = π_t·p^f_t + 0.5π_t·|p^f_t − p^p_t|**，草案化简正确（总费用再加紧急项 5π_t·e_t）。
3. **可调时段集合（补全定义）**：位置对齐约定（见②-0）下，τ∈{6,12,18}时发布覆盖钟点 τ+1..τ+24，
   即时段位置 T_6={37..144}, T_12={73..144}, T_18={109..144}；**位置 ≤6τ 的时段保持现行计划，不可调**
   （τ 所在的 10 分钟段：6:00-6:10 属位置36，其预报须由上一发布回填，为避免歧义直接划出可调集）。
   重优化以实际已达 SOC S^a(6τ) 为初态，对 T_τ 求解（含惩罚项的）LP，解替换 T_τ 上现行计划。
4. **"计划-调整-再调整"振荡（草案7.3担忧）**：不存在。调整只向前覆盖、无回退，且每时段生效量唯一，
   惩罚一次性结算；后续重优化改变的是 p^f，不新增计罚层。

### R4（任务指定）充放电效率90%的建模方向

**裁决：草案口径（充电 ΔS=+0.9c、c为母线侧吸收；放电储能侧放出 d、母线侧得 0.9d、ΔS=−d）符合题意，为主口径。**
依据：附录1"充放电效率为90%"为单一数值施加于充、放两个方向的惯例读法，往返效率0.81；
该口径与能量平衡式 p + PV·Δt + 0.9d ≥ L·Δt + c 自洽（c、d 同为决策变量，直接受 5000 kW 界：
c_t, d_t ≤ 5000·Δt = 833.333 kWh）。要求：
- 论文显式声明口径（c、d 各自的物理侧别 + 功率限施加在决策变量上）；
- 敏感性分析给出备选口径（仅充电侧损失：ΔS=0.9c、放电 d 全额上母线）下 P1 全天购电费的差值，
  预期差异 <10%（仅影响放电可用量的11%差额，且大部分时段功率界不 binding）；
- 实现为开关参数 `eff_conv ∈ {both, charge_only}`，全流水线可重跑。

### R5（草案7.4）紧急购电与充电同时段

**裁决：同意草案默认——充放电严格按计划执行，缺口全额由紧急购电（5π）补偿，此为题意口径。**
补充两条必须写进规范的执行侧规则：
- **SOC硬界强制（物理可行性，必须做）**：执行时 c^a_t = min(c^p_t, max(0,(10800−S_{t−1})/0.9))，
  d^a_t = min(d^p_t, max(0, S_{t−1}−1200))。截断导致的多余供给按弃光处理、不足计入缺口。
  报告全年截断次数/截断量（若占比可观，说明预报误差已使"严格按计划"失真，须在论文披露）。
- **缺口时段不暂停充电**（题意口径）：缺口 e_t = max(0, E_L^act + c^a_t − p^p_t − E_PV^act − 0.9d^a_t)。
  "暂停充电"变体（更现实但偏离计划）仅作为敏感性对照，报告年费用差与排名是否不变。
- 附带澄清：严格计划执行下，计划层持有"超额储备"无法减少紧急购电（c、d 已被计划锁死），
  因此 R1 中"储备缓冲"思路在 P2 主方案中不成立——P2 降低紧急费的正确杠杆是**预报侧分位数校正**（见 INN-3）。

### R6（草案7.5）弃光与售电

**裁决：确认。** 题目未给售电机制，售电不允许、弃光不违规不计费；"供电不可低于负载"仅为下界约束，
故执行侧供给>需求时剩余电量（含按计划购入但未用尽的电量）弃置，计划购电量仍全额按 π 计费
（题文"其他时间段的购电费用均按计划购电量计算"）。论文以假设 A-执行-1 显式声明。

### ②-1 P1（代表日，确定性LP）

**决策变量**：p_t, c_t, d_t, S_t（t=1..144），共576个。

$$\min \sum_{t=1}^{144} \pi_t p_t$$

s.t.
- 平衡：p_t + E_PV,t + 0.9d_t ≥ E_L,t + c_t，∀t（E_· 来自附件1：负载、光伏预测曲线）；
- SOC递推：S_t = S_{t−1} + 0.9c_t − d_t；S_0 = 6000，S_144 = 6000
  （题文"0:00与24:00储电量相同"+附录1初值6000，两条件合一）；
- 界：1200 ≤ S_t ≤ 10800；0 ≤ c_t, d_t ≤ 833.333；p_t ≥ 0。

**无需0-1变量（同时充放自然排除）**：交换论证——将 (c_t, d_t) → (c_t−δ, d_t−0.9δ) 保持 ΔS 不变，
平衡左端变化 −0.81δ、右端变化 −δ，松弛增大 0.19δ，可使 p_t 减小 0.19δ，费用严格下降（π_t>0）。
故最优解不存在同时充放时段，LP即足够（不必MILP）。

**输出**：表1（六个指定时段的购电量：按模板标签精确匹配 10:00-10:10、12:00-12:10、14:00-14:10、16:00-16:10、
18:00-18:10、20:00-20:10；全天购电量 Σp_t；全天购电费 Σπ_t p_t）；表2（六个4小时块的充电量 Σc、放电量 Σd：
块 k = 位置 24(k−1)+1 .. 24k；0:00 储电量=6000、24:00 储电量=6000）；result1.xlsx 按模板逐行填。

### ②-2 P2（全年逐日滚动：计划LP + 执行仿真 + 计费）

**框架**：对每日 D=1..365 依次执行三步（预报 → 计划LP → 执行仿真记账）。

**（a）信息集与预报器**。D日0:00可得：附件2中 D−1 及更早的实际负载/光伏、附件1电价。
主方案预报器（R2裁决）：
- 负载：L̂_{D,t} = L_{D−7,t}（同星期上周）；D−7 不存在（D≤7）时用 {D−1..D−7∩[1,∞)} 中同星期日均值，仍无则用附件1负载曲线；
- 光伏：P̂V_{D,t} = mean(PV_{D−1,t}, PV_{D−2,t}, PV_{D−3,t})（不足3日取可得均值；D=1用附件1光伏预测曲线）；
- INN-3分位数校正（见⑥）：对光伏预报减去、负载加上"近28日预报误差"的经验 q 分位（主方案 q=5/6，见⑥-3；
  q=0.5 为消融基线）。

**（b）计划LP（逐日，144×4变量）**：初态 S_0 = S^a_{D}(0:00)（D=1时6000，否则前日执行末SOC）。

$$\min \sum_{t=1}^{144} \pi_t p_t \quad \text{s.t.} \quad \hat{p}_t + \widehat{E}_{PV,t} + 0.9\hat{c}_t \ge \widehat{E}_{L,t} + \hat{c}_t,\ \ \hat{S}_t = S_0 + \textstyle\sum_{s\le t}(0.9\hat{c}_s - \hat{d}_s),$$
$$\hat{S}_{144} = S_0\ (\text{日循环，R1裁决})，\quad 1200\le\hat{S}_t\le 10800,\quad 0\le\hat{c}_t,\hat{d}_t\le 833.333,\quad \hat{p}_t\ge 0.$$

计划层不含紧急购电（平衡约束保证预报口径下供需平衡，故计划紧急量恒为0）。

**（c）执行仿真（用附件2实际值，逐时段）**：
- 充放严格按计划 + SOC硬界截断：c^a_t = min(c^p_t, max(0,(10800−S^a_{t−1})/0.9))；d^a_t = min(d^p_t, max(0, S^a_{t−1}−1200))；
- 供给 = p^p_t + E^act_{PV,t} + 0.9 d^a_t；需求 = E^act_{L,t} + c^a_t；
- **紧急购电触发与计费（题意）**：e_t = max(0, 需求 − 供给)；e_t > 0 触发，电价 = 5π_t（交易时刻电价的5倍，π_t 为附件1曲线）；
- 供给 > 需求：弃光处理，无成本；计划购电量 p^p_t 照全额按 π_t 计费（A-执行-1）；
- SOC更新：S^a_t = S^a_{t−1} + 0.9c^a_t − d^a_t；记录截断事件。
- **日费用**：C_D = Σ_t π_t p^p_t + Σ_t 5π_t e_t。

**（d）warm-up与统计口径**：D=1..31（1月）用同一策略完整仿真但不计入报告费用（D=1计划预报用附件1曲线）；
2025.2.1 的初态 SOC 取 warm-up 末值（主方案）；对照变体"2.1 重置 S=6000"须跑并报告年费用差（预期微小，用于证明 warm-up 无关紧要）。

**（e）输出**：result2.xlsx（三张sheet：计划购电量 335×147 逐日逐时段 + 全天购电量/全天购电费两汇总列；
充放电量逐日6块充/放电量 + 该日0:00与24:00实际储电量（执行值）共 335×8 行；紧急购电量按表4格式：
连续紧急时段**合并为一行**（如 13:00-13:30），日期格式 2025/3/1，模板每日3行不够时在日期组内插行）；
论文表3 = 指定4日期（2025.3.20/6.21/9.23/12.21，位置 D=79/172/266/355）各给：表1格式（计划购电量6时段+全天量费）、
表2格式（充放6块+0:00/24:00储电），另按表3格式给4日期的紧急购电结果。

**（f）对照基准（论文加分项，保留草案设计）**：
- B1 全年联合LP下界：变量 (p,c,d,S) 遍历全年 52560 时段，平衡式用**实际**曲线取等、SOC全年一条轨迹
  （S(1.1 0:00)=6000，仅界约束无循环），min Σπp。**下界命题**：任意执行策略费用 ≥ B1 最优值。
  证明：执行轨迹 (p^p+e, c^a, d^a, S^a) 满足平衡与SOC界，是B1的可行解；其总能量费用 Σπ(p^p+e) ≤
  Σπp^p + Σ5πe = 执行费用（π ≤ 5π）。∎
- B2 无储能基线：p_t = max(0, E_L,t − E_PV,t)，费用上界。
- B3 理论最优循环和（INN-1）：B1 最优值 = 1.1瞬变费用 + Σ_D 逐日循环LP(实际曲线)最优值，用于给出gap的分解证书。

### ②-3 P3（0:00计划 + 6/12/18时调整）

**实验设计（三臂消融，直接回答"是否需要引入其他时刻预报"）**：
- 臂0：0:00计划用附件3的0:00发布（位置对齐广播到144段），无调整，其余同P2 → 计量"附件3预报体系 vs P2 naive"的价值；
- 臂1：0:00计划 + 调整时刻子集 A ⊆ {6,12,18} → 计量"日内调整"的边际价值；
  子集消融：A ∈ {∅, {12}, {6,12}, {6,12,18}}（主方案 {6,12,18}），可加 {18}、{6}、{6,18}。
- 结论形式：年总费用表 + 每个发布时刻的边际价值（相邻子集费用差），按"值不值"给出明确回答。

**（a）0:00计划LP**：光伏预报 = 附件3当日0:00发布（位置1..144全覆盖，无缺口）；负载预报 = lag-7（同P2）；
目标与约束同P2计划LP，另加 **INN-3中位数校正**（光伏预报减去近28日"发布−实际"误差的经验中位数）；
日循环约束（R1命题在P2口径下仍适用，P3电价同样日不变）。

**（b）调整重优化LP（τ ∈ A，位置集合 T_τ = {6τ+1..144}）**：
- 初态：S^a(6τ)（实际执行至 τ−1 后的SOC）；
- 光伏预报：发布τ覆盖钟点 τ+1..τ+24 → 位置 6(τ+k−1)+1..6(τ+k)；T_τ 全部被覆盖（τ=6,12,18 均覆盖至位置144），
  **无需回填**（位置 ≤6τ 不在可调集内）；
- **目标（关键修正，见③-2）**：

$$\min \sum_{t\in T_\tau} \Big[\pi_t p_t + 0.5\pi_t (u_t + v_t)\Big] \quad \text{s.t.}\quad p_t - p^p_t = u_t - v_t,\ u_t,v_t\ge 0,$$

  平衡/SOC/界同前（预报更新）。min 使 u_t+v_t = |p_t − p^p_t|，即重优化**内嵌调整惩罚**，
  自动权衡"重新调度的能量收益 vs 0.5π偏离罚款"；
- 充放电量重优化不计罚（计费公式不含充放电）；
- 解替换 T_τ 上现行计划（p^f, c^f, d^f），时段 ≤6τ 保持不变。

**（c）执行仿真**：同P2，但 t∈T_τ 段用当前生效计划；缺口 e_t 仍按 5π_t 计。
**（d）日费用**：C_D = Σ_t π_t p^f_t + Σ_t 0.5π_t |p^f_t − p^p_t| + Σ_t 5π_t e_t。
**（e）输出**：result3.xlsx 四张sheet（计划购电量 = 0:00计划；调整购电量 = 各时段最终生效量 p^f
（未调整时段填计划值，使两sheet之差恰为被调整时段）；充放电量 = 最终实际充放；紧急购电量 = 最终实际）；
论文表3指定4日期：表1格式填**计划购电量**（与sheet口径一致，建议加"最终购电量"参考列并脚注）、
表2格式填最终充放、表3格式填最终紧急购电。

### ②-4 P4（波动电价）

- 电价 π_{D,t} = 附件4（日内10分钟级波动、日间水平也变）。**假设 A-P4-1（论文声明）**：D日0:00已知当天全天电价曲线
  （附件4即全天数据；若无此假设则0:00计划不适定）。敏感性对照：仅知 D−1 电价曲线（用前一日曲线做计划）时年费用变化。
- **P4-2（=P2换价）**：日循环约束在P4失效（R1），故用 **K日滚动LP**：对 D..D+K−1 联合优化
  （电价已知；负载/光伏用R2预报器外推K日；块内中间日 SOC 自由，仅块末不约束；每日执行仍只执行当日段）。
  主方案选择规则：先跑 K=1（当日内优化+日循环）与 K=7；若费用差 < 0.5% 取 K=1，否则取 K=7 并报告
  K=1 的次优性。输出 result4-2.xlsx（结构同 result2）。
- **P4-3（=P3换价）**：P3流水线，π 全部取附件4；违约/上浮/紧急的"交易时刻电价"= 该时段附件4电价。
  输出 result4-3.xlsx（结构同 result3）。K=1 为主（附件3发布只覆盖未来24h，跨日预报不可得——论文如实说明），
  K=7（跨日段用 D−1 的18:00发布回填预报）作为消融。
- 对照：全年联合LP下界（B1换附件4电价）。

## ④ 给coder的实现注意事项

1. **数据加载**：直接用 `data/data.npz`（price1/load1/pvfc1/(365,144)load/pv/fc_hours(365,4,24)/price4）；
   已验证无NaN、无负值；fc范围0–9995.9 kW。**fc对齐已实证**：发布τ的第k值对应钟点τ+k（shift=1的MAE全面优于shift=0：
   362 vs 972（0:00发布）等），即钟点 h=τ+k ↔ 位置 6(h−1)+1..6h。
2. **LP求解**：P1/单日计划LP规模≤600变量，任意LP求解器（scipy linprog/HiGHS、PuLP+CBC）秒级；
   全年联合LP（52560×4变量）建议 HiGHS 稀疏输入或按 INN-1 分解为逐日LP之和（等价且瞬时）。
   同时充放无需0-1变量（②-1交换论证），保持纯LP。
3. **调用量化**：P2/P3全流水线 = 335日 × (1~4次LP) + 仿真，单次全run应控制在数分钟内；
   消融矩阵（预报器2×2、调整子集4个、q网格5个、K∈{1,7}、执行规则2种、效率口径2种）注意缓存中间结果。
4. **结果文件**：严格按模板sheet名（计划购电量/充放电量/调整购电量/紧急购电量）与行列数写入；
   数值单位kWh；调整购电量sheet未调整时段填计划值；紧急购电连续时段合并；写完后加自检：
   行列数、指定日期行、Σ列与明细和一致（±1e-6）、充放电量sheet的24:00储电=仿真末SOC。
5. **执行仿真是唯一真相源**：论文所有费用 = 执行仿真输出；计划LP费用仅作对照。禁止用计划LP目标值冒充年费用。
6. **随机性**：全流程确定性（无随机算法），run两次结果须bit级一致；如用求解器含随机种子则固定。
7. **图表钩子**：入库时对每张论文图调用 figqa 的 assert_no_overlap（skill要求，coder接线）。
8. **数值口径**：S^a 递推保留全精度、输出四舍五入到0.1 kWh；费用保留2位；比较阈值统一用1e-6相对容差。

## ⑥ 创新清单（Innovation Ledger）

**INN-1（类型：解析刻画）跨日储运弱次优命题（"日循环定理"）**
- 主张：日不变电价 + 往返效率0.81 < 1 ⇒ 计划层跨日净储运弱次优 ⇒ P2/P3逐日循环滚动在计划层无最优性损失，
  全年联合LP可分解为"1.1一次瞬变 + 逐日循环LP之和"，并给出执行层gap的数值证书。
- 证据：②-2(f) B1/B3数值对照（预期gap≈0+紧急费项）；证明梗概见R1。
- **regime of validity**：仅P2/P3（价日不变）的计划层；P4失效（日间价差>往返损耗的情形存在），失效幅度由
  P4的K=1/K=7/下界三点对照量化——失效的量化本身是论文的对照实验。
- 为什么评委会在意：对手只能"跑两个模型报个gap"，本命题给出gap≈0的原因和失效边界，且直接支撑推荐策略
  （in-regime、load-bearing），不是装饰性引理。

**INN-2（类型：更难题的回答）调整时刻的边际价值消融**
- 主张：把P3"是否需要引入其他时刻预报"从yes/no升级为各发布时刻的边际价值排序（子集消融 + 价格加权度量）。
- 数据预筛（窗口匹配MAE，kW）：下午-晚间窗口 0:00发布351 → 6:00发布306 → 12:00发布272；
  晚间误差虽小（≈18 kW）但恰逢最高价1.3952元/kWh与5×紧急价，故18:00发布价值必须以费用而非MAE度量。
- 证据：②-3(a)四子集年费用表；结论若为"调整不省钱"（臂1−臂0≥0）则如实报告并以预报负技巧解释
  （附件3各发布对实际均为负技巧：341 vs 持续性165——这本身是重要发现，必须在论文呈现）。
- regime：P3/P4-3的预报-计费结构；对预报器实现细节稳健（消融内验证）。
- 为什么评委会在意：把开放问题变成可决策排序，且揭示"官方预报差于持续性"这一反直觉数据事实。

**INN-3（类型：非显然机制）newsvendor型分位数校正预报器**
- 主张：计划层预报应按"过剩/缺口单价比"做系统性分位数偏置，而非无偏使用：
  - P2/P4-2：缺口单价5π、过剩单价π ⇒ 预报误差缓冲取分位 q* = ρ/(1+ρ), ρ=5 ⇒ q*=5/6（newsvendor临界分位数）；
  - P3/P4-3：计费 πp^f + 0.5π|p^f−p^p| 对执行需求为|·|损失 ⇒ 计划取执行需求的**条件中位数**（q*=1/2，中位数引理），
    且校正方向由附件3发布的系统性偏差实证确定（0:00发布高估光伏：白天逐时MAE 341 vs 持续性165）。
- 证据：q ∈ {0.5, 0.6, 5/6, 0.9} 网格 × {P2, P3} 全流水线年费用U形曲线；闭式q*预测值 vs 仿真最优q的吻合度；
  校准窗（2–6月）训练、7–12月out-of-sample验证。
- regime of validity：价格比恒定、误差分布平稳、忽略SOC/功率界耦合的边际近似（耦合使q*偏移，由仿真q为准，
  闭式q*为解释）。P2无调整费、P3有——两问题q*不同且方向可解释，即模型的内部一致性检验。
- 降级条款：若oos增益 < 0.3%年费用，则不作headline，降级为敏感性分析并明示，避免过度声明。
- 为什么评委会在意：几乎所有队伍把预报原样喂进LP；本项证明"计划应当故意少信光伏/多备负载"，
  有闭式一阶条件、有可复现标定、有oos证据，且直接改善两个headline数字。

**Award-ceiling 自评**：三项均为"非显然机制/解析刻画/更难题回答"，无一依赖合成数据的生成过程知识
（INN-1用价日不变性——题目结构而非数据秘密；INN-2/3用计费规则与误差分布——数据可观测）。
若INN-3被oos证伪则降级不虚报；INN-1/2不依赖该风险。
