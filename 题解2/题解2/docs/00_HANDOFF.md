## 3. 模型（最终版，全部LP，无整数变量）

### 3.0 统一记号
时段 t=0..143；决策：购电 p_t≥0、充电 c_t∈[0,833.33]、放电 d_t∈[0,833.33]（kWh）；S_t 时段末SOC∈[1200,10800]。
平衡：`p_t + PV·Δt + 0.9·d_t ≥ L·Δt + c_t`（缺供→紧急购电；过剩→弃光）。
SOC：`S_t = S_{t-1} + 0.9c_t − d_t`。

### 3.1 P1：单日确定性LP
min Σπ_t p_t，S(0)=S(24:00)=6000。附件1全部曲线已知。

### 3.2 P2：逐日两阶段SAA随机规划（核心方法创新）
- **预测**（仅0:00可得）：负载=上周同期 L[d−7]（MAPE 3.96%，vs naive 15.97%）；光伏=近3日均值（MAPE 6.42%，vs naive 7.70%）。
- **场景**：K=15个"实际−预测"误差样本（最近15天）叠加基准预测，截断非负。
- **计划LP**：`min Σπ p + 5·Σ_k w_k Σπ e^k`，场景平衡约束 `p+PV^kΔt+0.9d+e^k ≥ L^kΔt+c`，日末SOC=日初=6000（日循环）。
  - **日循环合理性（modeler命题INN-1）**：日不变电价+往返效率0.81<1 ⇒ 跨日储运弱次优，计划层零损失；P4失效（日间价差>0.15元/kWh）故P4用两日滚动。
- **执行**：p/c/d严格按计划；缺口 `e=max(0, LΔt+c−p−PVΔt−0.9d)` 按5π计费。
- 1月为warm-up（跑但不输出），输出2025.2.1–12.31。

### 3.3 P3：P2框架 + 光伏用附件3的0:00预报 + 6/12/18时滚动调整
- 0:00计划：光伏=附件3的0:00预报曲线，负载=lag-7，SAA场景（fc0误差样本）。
- 调整时刻：6:00（t0=42起，即预报可覆盖的7:00起）、12:00（t0=78）、18:00（t0=114）。SOC取计划轨迹值，日末=6000。
- **调整LP目标内嵌违约惩罚**：`min Σ[π p_t + 0.5π u_t] + 5Σw_kΣπ e^k`，u_t≥|p_t−p_plan,t|（线性化）。
- 计费（modeler代数确认）：`总费用 = Σπ·p_final + 0.5Σπ|p_final−p_plan| + 5Σπ·E`。
- **是否需要其他时刻预报（题目问）**：A(仅0:00)=1505.2万 > C(naive无预报)=1489.4万 > B(调整)=1474.1万。B比A省31.1万(2.1%)、比C省15.4万(1.0%)。**结论：需要，但收益有限**（附件3预报已准，corr≈0.99；0:00预报+场景法已消化大部分不确定性）。调整主要价值在正午预报对午后时段的修正（如9-23日12:00时段计划658.9→调整497.6 kWh）。

### 3.4 P4：波动电价 + 两日滚动
- P4-2/P4-3 = P2/P3框架，电价换附件4；**窗口改两日**：每天解[d,d+1]两天LP（今天带15误差场景、明天点预测；今天日末SOC自由、明天日末=6000），执行今天，明天重优化。
- 跨日套利价值：P4-2从日循环1554.3万中的改善已含（vs 日循环版1581.7万省27.3万）。
- 假设A-P4-1：0:00已知当天电价曲线（题目未给电价预报，标准做法，论文需声明）。
