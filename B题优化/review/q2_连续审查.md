# Q2 连续 minimax 数学审查与有理数证书

审查日期：2026-09-11。独立数学审查；未修改旧成果。

## 结论与适用范围

在标准化坐标下，令首测点为原点，首次输出示向度为 0°，源的首次可行域为完整扇区

\[
P_1=\{r(\cos\phi,\sin\phi):5<r\le1500,\ |\phi|\le1.005^\circ\},
\qquad
C=\{(a,b):650\le a\le850,\ 200\le|b|\le400\}.
\]

本报告证明的候选点为 \(q_0=(850,400)\)，负侧由反射得到 \((850,-400)\)。**完整扇区条件不可省略**：如果首次区域另被已知地图边界 \(\Omega\) 裁剪，下文连续上界依然有效，但全局下界的见证点可能失效，不能继续声称同一个全局近最优结论。首次点为圆形场地中心且场地半径至少 1500 米时不存在这一裁剪问题。

定义保守连续模型

\[
F_c(q)=\sup_{\theta\in\mathbb S^1}\rho(P_1\cap W_{1.005^\circ}(q,\theta)).
\]

空后验不参与上确界，等价地可记半径为 0。在允许各次物理误差取任意 \([-1^\circ,1^\circ]\)、输出四舍五入到 0.01° 的有界误差模型中，另记真实可实现读数与后验的最坏半径为 \(F_Q(q)\)。它不是固定哈希噪声模拟器某个已知确定函数的经验表现。

独立标准库程序用**精确有理数运算**验证：

|目标|全候选区下界|候选点上界|候选点与全局最优的差距上界|
|---|---:|---:|---:|
|连续保守半角 1.005° 模型|64.47229 m|64.473 m|0.00071 m|
|±1° 物理误差、0.01° 量化模型|64.38469 m|64.473 m|0.08831 m|

这里的“近最优”有明确目标和候选区；没有证明全场任意第二测点、移动时间、多步定位策略的全局最优，也没有宣称角点就是唯一的精确最优点。

## 1. 连续第二读数的上界分支

设角度区间 \(I=[\theta_c-\delta,\theta_c+\delta]\)，在一个正确展开的角度坐标内处理。只要 \(\varepsilon+\delta<90^\circ\)，

\[
\bigcup_{\theta\in I}W_\varepsilon(q,\theta)
\subseteq W_{\varepsilon+\delta}(q,\theta_c).
\]

这是圆周角距离的三角不等式。对任意外包集合 \(P_1^+\supseteq P_1\)，由最小包围半径对集合包含关系的单调性，

\[
\sup_{\theta\in I}\rho(P_1\cap W_\varepsilon(q,\theta))
\le\rho(P_1^+\cap W_{\varepsilon+\delta}(q,\theta_c)).
\]

进一步，右端无需计算“严格最小”的圆：**任意经验证覆盖右侧多边形全部顶点的圆，都提供严格上界**。凸性保证该圆同时覆盖所有边和内部点。这一点使浮点候选圆心可以和精确有理数证明安全分离。

若当前所有区间上界的最大值为 \(U\)，实际可行读数下的见证下界最大值为 \(L\)，则 \(L\le F_c(q)\le U\)。每次平分最大上界区间，直到 \(U-L\) 达到目标容差。中点、端点只是更新下界的工具；连续保证来自覆盖完整角度区间的上界分支。

对 \(b>0\) 的候选区，全部可行源的纵坐标均低于 \(q_y\)，因此真实位置角属于 \((-180^\circ,0^\circ)\)。含误差后的所有读数可用 \([-182^\circ,2^\circ]\) 覆盖。精确证书直接覆盖这个统一区间，规避角度范围计算本身的浮点误差。初始分成 8 个 23° 区间，始终满足扩展半角小于 90°。负侧按反射对称处理。

一般固定 \(q\notin\operatorname{conv}(P_1)\) 时，也可从外包凸多边形顶点的位置角，取一个不跨断点的最小覆盖弧，再外扩误差半角。若 \(q\) 在首区域内部或无法证明覆盖弧小于 180°，应直接覆盖整圆并先分成足够短的区间，不可简单取 `atan2` 数值的最小和最大值。

## 2. 首扇区圆弧与外包误差

C++ 探索程序同时构造首扇区的内接与外切多边形，使用 `long double` 和 1 微米数值余量。64 段划分仅覆盖宽度 2.01° 的圆弧，单段约 0.0314°。外切弧的径向误差不超过

\[
1500\{\sec[(2.01^\circ/64)/2]-1\}<0.000057\text{ m}.
\]

不过，不能只凭这个首区域 Hausdorff 误差就断言任意截锥后包围半径也具有同样的误差；近切交会可能放大误差。程序直接对截锥后的内外集合计算界，避免这一推断。

精确有理数证书使用更简单的外包：从

\[
0\le x\le1500,\qquad |y|\le x\tan\varepsilon
\]

构成的三角形出发，再加入圆 \(x^2+y^2\le1500^2\) 在角度 \(\pm\varepsilon\) 处的两个切平面。每一个切平面都包含完整圆盘；因此外包包含全部首扇区圆弧，无须逐点采样圆弧。三角函数系数以有理数区间包围，半平面右端再加入足够覆盖系数误差的余量。

上界中把 \(r>5\) 放宽为 \(r\ge0\) 是保守处理。下界不使用原点或内圆禁区内的点：所有解析见证距离首点至少 1236 米。C++ 的点对下界也显式筛除 \(r\le5\) 的顶点。

## 3. 整个连续测点候选区的解析下界

只考虑正侧 \(650\le a\le850,200\le b\le400\)。取首角半宽 \(e_1\)，另取用于构造见证对的第二半角 \(e_2\)。设

\[
A=R(\cos e_1,-\sin e_1),\quad
B=t(\cos e_1,\sin e_1),\quad R=1500.
\]

令从 \(q=(a,b)\) 指向 \(A\) 的射线顺时针转过 \(2e_2\)，与上侧首观测射线相交于 \(B\)。交叉乘积解得

\[
t(a,b)=\frac{R(ka+hb)-s(a^2+b^2)}{R\ell+hb-ka},
\quad
k=\sin(e_1+2e_2),\ h=\cos(e_1+2e_2),
\ s=\sin(2e_2),\ \ell=\sin(2e_1+2e_2).
\]

这是真实射线交点，不能仅凭两条直线的叉积方程就省略方向检查。程序验证：分母为正、\(t>5\)、\(t\cos e_1>850\)、\(t\sin e_1<200\)。两见证点相对所有候选 \(q\) 均位于右下方向，旋转角只有约 2°，所以不可能误取反向射线交点。

若两个见证点能共同对应一个第二读数，则任何覆盖该后验的圆都必须覆盖 \(A,B\)，从而

\[
F(q)\ge H(t(q)):=\frac12\sqrt{R^2+t^2-2Rt\cos(2e_1)}.
\]

令 \(D=R\ell+hb-ka\)。两个偏导的分子展开为

\[
D^2t_a=R^2k\ell+2Rkhb-2saR\ell-2sahb+sk(a^2-b^2),
\]

\[
D^2t_b=R^2h\ell-2Rhka-2sbR\ell+2skab+sh(a^2-b^2).
\]

对整个矩形进行精确区间代入即可证明两者为正；无需枚举测点。连续模型的保守数值摘要为

\[
D>260.17,\quad D^2t_a>10208.17,\quad D^2t_b>30302.69,
\]

并且

\[
1236.25<t\le1381.354<1500\cos(2e_1).
\]

因此 \(t\) 随 \(a,b\) 增大而增大；\(H(t)\) 在这个范围内严格减小。全候选区见证下界的最小值出现在 \((850,400)\)：

\[
\inf_{q\in C}F(q)\ge H(t(850,400)).
\]

注意，这里证明的是**见证下界**单调，不是未经证明地声称完整后验目标处处单调。用角点上界与该全局下界夹逼，已经足够给出近最优保证。

## 4. 连续误差和合法量化读数须分开

连续保守模型的见证使用

\[
e_1=e_2=1.00499999^\circ<1.005^\circ.
\]

这给出下界 \(64.4722934230099\ldots\) 米。首次角度向内缩 \(10^{-8}\) 度，用来避免量化边界和浮点边界约定争议；证书直接断言这个下界至少是十进制有理数 64.47229 米。

物理误差 ±1°、0.01° 量化的见证则使用

\[
e_1=1.00499999^\circ,\qquad e_2=0.99999999^\circ.
\]

两见证点的位置角相差 \(2e_2\)。将其中间方向四舍五入到最近的 0.01° 输出 \(\theta_Q\)，每个点与 \(\theta_Q\) 的角度差都严格小于

\[
e_2+0.005^\circ=1.00499999^\circ<1.005^\circ.
\]

因此可以各选择一个绝对值不超过 1° 的物理误差，使两个潜在源均输出同一个 \(\theta_Q\)。首次输出 0° 同理可实现。这是对“同一观测对应两个不同可能世界”的构造，不要求同一源同时出现两种误差。严格内缩避免了恰在 0.005° 舍入中点时 `round` 平局规则的差异。由此得到整个候选区的合法量化模型下界 \(64.3846900369349\ldots\) 米。

**不能**把在任意实数 \(\theta\) 找到的连续下界直接充当合法量化模型的下界。C++ 表中另穷举了覆盖弧内全部 0.01° 读数，但其很小的上下界间隙仍只是长双精度数值夹逼；真正的有理数全局证书使用上面的独立见证论证。

## 5. 有理数证书为何不依赖浮点正确舍入

程序 `src/q2_rational_certificate.py` 仅使用 Python 标准库。

1. 用 Machin 恒等式 \(\pi=16\arctan(1/5)-4\arctan(1/239)\)，结合反正切交错级数首个遗漏项，得到 \(\pi\) 的有理数上下界。恒等式可由正切加减公式和角度所在象限核验。
2. 度数是精确 `Fraction`；将相应弧度约为分母 \(10^{20}\) 的有理数，保留由 \(\pi\) 区间和舍入引起的完整误差。
3. 用 32 项正弦/余弦泰勒和首个遗漏项包围真实值，再用导数绝对值不超过 1 把弧度误差传播回来；最终向外取整到分母 \(10^{20}\)。实际调用范围 \(|x|<4\)，遗漏交错尾项的绝对值递减。
4. 把三角函数法向量区间换成有理数中点法向量，并在右端加入 \(3000(\Delta n_x+\Delta n_y)/2\)。首扇区所有坐标、以及相对候选点的两个坐标绝对值均小于 3000，故该平面仍为外包。
5. 半平面裁剪、顶点交点全部由 `Fraction` 运算获得。浮点数只用来提出一个较好的圆心；随后将圆心明确写成 12 位十进制有理数。
6. 对每一个分支叶子，用精确整数/分数运算验证全部顶点满足 \(\|z-c\|^2\le(64473/1000)^2\)。只有验证成立才接受叶子，否则继续平分。程序还验证叶子首尾和相邻端点，确保无空隙覆盖 \([-182,2]\)。
7. 全局下界中的根号使用整数 `isqrt` 构造向外界，随后精确比较已声明的十进制下界。

结果共计算 166 个区间节点。输出 JSON 保存每个叶子的精确角度端点、十进制有理数圆心以及顶点数量，运行程序可重新生成并核验全部几何。JSON 内近似浮点展示值不作为证明依据；`certified_floor_m` 和 `upper_m` 的有理数断言才是报告结论。

这属于明确算法与精确算术支撑的可复核计算证书，未使用定理证明器对 Python 解释器或整个程序进行形式化验证。

## 8. 一般裁剪首区域下的后续方法

若未来需要处理任意 \(P_1\cap\Omega\)，本报告解析见证未必仍在区域内。可保留固定点上界算法；测点区间下界可用以下保守构造，但本次未对裁剪情形运行全局优化。

对半径为 \(h\) 的测点子块，中心为 \(q_c\)，设 \(d_0=\inf_{z\in P_1}\|z-q_c\|>h\)。测点位移引起的单条位置角变化不超过 \(\gamma=\arcsin(h/d_0)\)。任取

\[
Z\subseteq P_1\cap W_{\varepsilon-\gamma}(q_c,\theta),
\]

则对该块全部 \(q\)，都有 \(Z\subseteq P_1\cap W_\varepsilon(q,\theta)\)，所以 \(\rho(Z)\) 是该测点块的下界。若要合法量化，\(\theta\) 应直接取量化格点，或再留 0.005° 的角度余量。该方法须有 \(\gamma<\varepsilon\) 才有用；在距首区域仅约 185 米时，块尺度往往需降到数米，因此可能较慢。本次完整扇区的解析单调见证避免了这项开销。
