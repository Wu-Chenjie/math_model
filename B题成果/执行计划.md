# B题建模、计算与论文交接计划

目标：逐问完成可验证模型，以 C++ 执行策略和批量仿真，交付有数值证据的简体中文论文撰写交接文档、图表、源代码、复现实验及独立评审。

架构：`src/geometry.hpp` 对应问题1和2；`src/policy.hpp` 对应问题3和4；`src/experiment.cpp` 负责隔离真值的本地仿真；`src/robot.cpp` 通过标准输入输出与 Python HTTP 薄桥通信，策略不读取真值。`src/report.py` 只处理统计和绘图。保留原始模拟器，不修改其物理规则。

- [x] 规格与数学核验：对照题面、附件和参考思路；纠正两位小数的误差外扩；独立验证覆盖与反例。
- [x] 先写几何和物理边界断言，再实现半平面交、最小包围圆和统一费用。
- [x] 实现七点／三角网格覆盖、批量发现、局部主动定位、有限光学兜底及退出证书。
- [x] 固定开发集选择参数；冻结独立测试集；保留同案例消融和极端压力测试。
- [x] 接入已有 Python 模拟器，执行原物理核与真实 HTTP 接口演练，核对 C++ 自建物理与总费用。
- [x] 本地统计均值、分位数、配对差异置信区间；输出 PDF/SVG/PNG 图与逐局 CSV。
- [x] 写交接文档：摘要、重述、假设、符号、理论、四问模型、结果、验证、局限、可复现命令和正式测试留档流程。
- [x] 完成后另行安排独立方法 reviewer 和模拟评分 agent；逐条修订后复核引用与数值。

实验口径：队内模拟结果始终标明“本地模拟”，不能替代官方三次正式测试。未提供官方登录与日志时，官方表格状态标注未执行，不编造案例编码。优先在当前目录独立新增 `B题成果`，不改动已有 C题成果。

参数预声明：候选定位偏移先用(750,±300)m；保守误差半角1.005°；三角格比较h=900、950、990m；提前清除半径阈值比较20、35、50m。开发种子1—40；最终测试种子10001—10200，最终测试不用于再次选参。极端测试覆盖1000m半径、边界向外、±1°固定误差与同地重测。
