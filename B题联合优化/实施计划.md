# 联合调度与机会观测优化

目标：相对上一轮两步DP（B题动态规划默认）争取问题3、4新独立同案例总耗时下降超过10%，完整清除为约束。性能达标与否由实际数据判断，不替换基线或删去不利案例。

1. 将时间分为扫描、局部决策、光学兜底，开发seed1—40作诊断。
2. 单独测试覆盖点处补测已发现频道：合理距离和横向基线筛选，保留每频道次数上限。
3. 单独测试动态动作节点与全局排序联动：每次真实动作之后返回全局调度，记录每源已用动态动作总数；用完后进入原有限完成流程。
4. 组合测试机会观测与联动调度。按开发集选参后冻结。正式独立评价在选参结束之后，使用新seed1510001—1510200；五类压力组1520001—1560001起每问40环境。
5. 若不足10%，继续基于开发集诊断新增机制；已经打开的独立集不再用于选参，后续新版本改用预先声明的新独立种子。
6. 输出可执行入口、前后配对原始数据、统计区间、变差个案、复现脚本和验证报告。保持既有冻结目录。

评估优先使用总虚拟耗时的配对均值比，单源均时另列。主基线始终是上一轮两步DP，不把累计相对旧版本的改进混称本轮10%提升。
