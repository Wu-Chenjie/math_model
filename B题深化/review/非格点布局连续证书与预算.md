# 非格点布局的连续证书与预算

本轮目标是把旧25点缩减至20—22点。下面提供可独立复算的充分证书和候选筛选规则，尚不把任何未认证的20、21或22点数值候选写成已证明构造。证书与新试验均写入`B题深化`，未改旧成果。

## 1. 需要证明的精确几何条件

令S为有限固定测点集，Ω为半径1800的闭圆域。对任意z∈Ω，定义近邻集 `S_z={s∈S:|s−z|≤1000}`。全连续位置、全发射半平面朝向的覆盖等价于

\[
z\in\operatorname{conv}(S_z),\qquad z\in\Omega.
\]

充分性来自凸组合；必要性来自凸集严格分离。如果z不在近邻凸包内，存在朝向让所有1000米内测点都处于无效半平面。这个条件同时处理内点、圆周、切向发射和闭接收边界。

数值搜索可对每个采样z检查近邻测点的凸包，而不是只检查最近距离、三重圆覆盖或到某个三角形的距离。三重距离覆盖仍不足以保证三个近邻从方向上包围z。另一方面，搜索样本全部通过也不构成连续证明。

## 2. 推荐证书：公共近邻凸包覆盖自适应单元

先构造包含Ω的有理凸多边形Q，把Q剖分为闭三角形。对每个三角单元τ，选公共安全集

\[
S_\tau=\{s:\max_{v\in\operatorname{vert}(\tau)}|s-v|\le r_c\},\quad r_c\le1000.
\]

若τ的三个顶点都在conv(Sτ)中，则τ内每个z也在该凸包中；又因圆盘凸，z距Sτ中每个测点均≤r_c。于是τ内所有z均满足上一节条件。每叶可以使用不同测点组合，不要求全局固定的测点三角剖分。认证失败的τ可沿最长边二分继续检查。

这允许某条测点间边长超过1000，只要证明某些目标小单元所需的测点各距整个单元≤1000。它比“Delaunay中所有有关边都≤1000”宽松，适合20—22点非格点布局和两圈布局。边界单元同样被完整覆盖，不能把目标圆替换成内接多边形而忽略薄环。

独立实现是`review/adaptive_cover_certificate.py`。输入坐标用Fraction按JSON原始十进制精确解释；浮点仅用来提议可能安全的点，最终距离平方和凸包叉积比较均为有理数。每个叶子的根三角形编号、二分路径和安全凸包顶点编号保存到JSON，`--verify`从外包多边形重建整棵分割树，核验无遗漏、无额外叶子并重验所有几何条件。有限深度返回UNKNOWN仅表示该证书未完成，不是布局不可行证明。

Q由精确单位有理法向构造。取 `t=k/n`、`u=((1−t²)/(1+t²),2t/(1+t²))`，旋转至四象限；每个u严格满足|u|=1。相邻切线 `u·x=1800` 的交点为有理数，全部内侧半平面交构成Q⊃Ω。n=32产生128个切线方向，Q顶点最大半径1800.878691778；n=128使外扩进一步减小到约0.055米。n可以增大，不能把外包方向改成内接顶点。

复现示例：

```powershell
python 'G:\math__model\B题深化\review\adaptive_cover_certificate.py' POINTS.json CERTIFICATE.json --n 128 --maxdepth 24 --reception 999.9
python 'G:\math__model\B题深化\review\adaptive_cover_certificate.py' CERTIFICATE.json --verify
```

输入可为`[[x,y],...]`或`{"points":[[x,y],...]}`；坐标也可直接用字符串保留原始十进制。建议使用999.9或999的认证接收半径，给正式1000米门限留下严格裕量。证书还报告全部叶子的最小凸包支持线距离；若其也严格为正，则可用它与1000−r_c一起控制最终坐标舍入：各测点扰动小于这两者时，近邻距离与凸包包含同时保持。只留距离裕量而不检查凸包支持线裕量，不能自动声称任意位置舍入都安全。

阳性验证：旧25点的十进制坐标在n=32、最大深度24下认证成功，共17420个访问节点、8774个叶子，生成约2.63秒；独立`--verify`重放全部8774叶成功。该结果检验证书实现可以处理现有已知连续构造，不用于宣称新候选已经通过。

追加严格阈值验证：`legacy25_strict_certificate.json`以999.9米认证成功，共8840叶，最小凸包支持线距离0.00285141447米；独立重放通过。人为删除一个叶子的篡改证书被拒绝，空布局返回UNKNOWN。该结果还验证了接收阈值参数与完整分割树核验逻辑。

## 3. 较简单但较强的备选证书

对S做任意无重叠三角剖分，先证明conv(S)包含Ω。每个与Ω相交的三角形T，若对其三个测点顶点s均有

\[
\max_{z\in T\cap\Omega}|z-s|\le1000,
\]

则所有目标位置被认证。超长边完全在Ω外不必一概拒绝；应检查T∩Ω而非整个T。若边的一端位于Ω内，该端本身仍在被检集合中，所以与其相连的另一个三角顶点不能超出1000；这一限制解释了固定三角剖分为何可能过于保守。

圆域相交最大距离可有限计算：检查T内的原三角顶点、每条边与圆周交点，以及s的圆周反向点 `−1800s/|s|`（若属于T）。线段上的距离平方是凸函数，最大值在端点；圆弧最大值在端点或反向点。实现严格根式区间比较需要额外工作。更易独立复算的保守版本是用上一节Q替代Ω，对有理多边形T∩Q的所有顶点做精确平方距离检查。

## 4. 对同心圈候选的建议与限制

中心+8内点+12外点或中心+7内点+13外点均为21点，适合低维半径、相位搜索，再局部放松点位置。候选的外圈凸包必须包住Ω；正m边形外圈半径至少 `1800 sec(π/m)`，这是必要条件而不是接收充分条件。少量非规则外部点也可能改善边界覆盖和内外圈连接。

中心点并不能让内圈半径1000的所有邻域自动安全。如果数值目标函数只在离散半径取样，可能忽略z→0方向上的临界接收变化。应取内圈半径严格小于所要求认证阈值，并在搜索评分中显式处理这些极限；最终仍以连续证书为准。

若强制中心扇形三角剖分全部边≤1000，则内圈半径≤1000。若还把每个相邻内圈点和某个外圈点组成三角形，会要求该外圈点同时距两个内点≤1000。这比实际连续凸包条件强，可能把有效的21点布局错误淘汰。优先让公共近邻自适应证书决定所需局部组合。

减少点数可在通过21点认证后尝试移除中心或一个内圈点，并重新优化其余点；移除后的连续证书必须重新生成，旧证书不能复用。通过21点不会证明20点不可行；此前固定通用测点下界14仍适用，故若21点最终认证，应表述14≤N_opt≤21。

## 5. 相同定位策略下的统一预算

以下保持上一轮原地机会补测及局部定位代码不变，设新固定测点数N、最大原点半径R_g。每源局部measure≤9，clear≤111；原地补测不增加移动。取

\[
B=\left\lceil\max\{R_g+\sqrt{750^2+300^2},\sqrt2\,1800\sec(\pi/64)\}\right\rceil.
\]

其余定位位置界与上一轮相同。全局长移动段至多N，16源局部每源至多12段，包括进入光学兜底；每源光学内部路径≤2996米。于是

\[
L\le2B(N+192)+47936,
\quad N_m\le20N+144,
\quad N_{clear}\le1776,
\]

\[
N_{有效动作}\le20N+1922,
\qquad T\le L/5+120N+6224\text{秒}.
\]

例如，仅当最终布局已经证明R_g≤1900米时，可以统一取B=2708：

|N|有效动作上界|T上界/虚拟秒|虚拟小时|
|---:|---:|---:|---:|
|20|2322|247849.6|68.847111|
|21|2342|249052.8|69.181333|
|22|2362|250256.0|69.515556|

若外点半径超过1900，必须代入实际R_g重算，不能照搬此表。预算仍以合法观测、保守定位集正确维护和请求完成为前提，不保证现实20分钟内通信完成。路线2-opt只改代理开路径长度，不保证这些上界变紧，也不保证每个实际案例的总T下降。
