# 第三轮固定机制实验

布局只依据连续覆盖证书冻结：中心、8个995米内环点、12个1864米外环点，共21点；认证接收阈值998米。路线和局部定位参数沿用第二轮，未以分层耗时调参。

对照方法：0=首版31点最近邻；1=第二轮25点联合规划+原地补测；2=本轮21点联合规划+原地补测。问题3三种方法仅0与1/2路线不同，1和2应完全一致。

全因子：源数10/13/16；问题4定向源比例20%/50%/80%（四舍五入到整数且两类都存在）；边界源比例0/50%/100%，边界定义半径1650—1800米；几何模式均匀角分布、近共线、角向聚集。问题3定向比例固定0。

每个核心单元30个案例：接收半径1000/1250/1500、误差场5种、定向方向随机/向外三因子的全部30个组合各一次，使用同一确定性种子规则。问题3仍记录方向模式但它没有物理作用。总计问题3的810个、问题4的2430个基础环境，三方法共9720次策略运行。图表按案例配对，不把同一环境下的方法视作独立样本。

额外记录源位置协方差最小/最大特征值比，作为几何退化指标；数据由评估器在调用策略前计算，只用于分层，不输入策略。源坐标不要求40米最小间隔，检验策略对密集源的独立性。

所有边际组、各完整因子单元、最差单元及获胜比例都报告；不只挑有利组。若有完整因子单元新方法更慢，明确保留。区间为案例配对均值差的描述性95%t区间；多组区间不当作同时95%置信，受控场景与固定配额并非官方随机分布。

仍有分布无关保证的只有完整覆盖、有限完成和虚拟时间上界。无论分层多广，都不把观测到的平均优势表述为对任意未知分布普适。
